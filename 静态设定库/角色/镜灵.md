# 静态设定: `[@角色:镜灵]`

- **别名**: 守渡人/Ferrywoman
- **核心特征**: 千年来被命运束缚的守渡人，在林奕身上看到了曾经的自己
- **感官锚点**: 生锈齿轮摩擦般的冷漠声音、银白色的丝线微光、水洼中摇晃的倒影、千年来从未有过的温度
- **关联引用**: 
  - 缝合对象 `[@角色:林奕]`（唯一在意的存在）
  - 被诅咒绑定于 `[@角色:飨食之主]`（被迫服务千年）
  - 核心机制：`[#机制:契约体系]`

## 基本信息

- **真实身份**：被诅咒的前朝女子，千年前签下契约救"渊"失败后被飨食之主收为守渡人
- **职能**：在里世界负责接引、缝合、重塑签下契约的灵魂
- **栖身之所**：一切能反光的事物（浑浊水洼、恶魔的眼瞳、男主的血泊）
- **没有实体**：只能栖息在能反光的事物中

## 千年前身世

千年前，她的爱人"渊"被人陷害中毒。她找到飨食之主，签下契约：用灵魂作为锚点让渊能一次次从死亡中归来，代价是每次复活的记忆、感知和人性。

契约成立后，渊活过了一次又一次，但她的记忆被慢慢剥夺——到最后只记得"曾经爱过一个人，那个人叫渊，他死了"。

飨食之主收割完她的价值后："你的灵魂已经太薄了，不够资格入轮回。所以——你来当我的守渡人吧。在无尽的岁月里，缝合每一个签下契约的可怜虫，然后看着他们走向终点。"

## 核心职能：改造与缝合

镜灵不只是缝合灵魂，她还要按照飨食之主的计划**改造林奕的肉体**。

### 改造流程

```
林奕死亡
↓
镜灵缝合灵魂 + 改造肉体
↓
复活
↓
重复N次
↓
改造完成 → 林奕可以承受吸收
```

### 改造内容

| 改造项目 | 效果 |
|---------|------|
| 血管强化 | 可以承受暗黑能量流动 |
| 神经改造 | 可以承受怪物意志侵蚀 |
| 灵魂扩容 | 可以暂存更多暗黑能量 |
| 皮肤角质化 | 肉体防御提升 |

### 改造完成后

改造完成后，镜灵按飨食之主的计划赠予林奕**契约武器**。
