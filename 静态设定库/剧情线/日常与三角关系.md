# 日常与三角关系

- **ID**: `[#剧情线:日常与三角关系]`

## 核心策略：制造"虚假接近感"

**男主的苦楚不是来自"得不到"，而是来自"明明那么近却永远无法触碰"。**

## 日常场景类型

| 类型 | 设计 | 效果 |
|------|------|------|
| 虚假暧昧 | 白露误以为喜欢男主或某种误会 | 读者心疼男主 |
| 共处时间增加 | 白露主动找男主帮忙/学习/聊天 | 男主内心狂喜但知道是假 |
| 王子线丰富 | 白露和王子有更深的羁绊 | 男主每次看到都像被刀割 |
| 特殊事件 | 某个危机让白露短暂依赖男主 | 短暂"错觉"后更深的绝望 |

## 三角关系结构

### 男主 vs 王子

| 维度 | 林奕 | 王子 |
|------|------|------|
| 身份 | 普通男高中生 | 真正优秀的完美之人 |
| 与白露 | 暗恋十年不敢告白 | 青梅竹马家族世交 |
| 性格 | 沉默笨拙不善表达 | 温柔守护理所当然 |
| 处境 | 永远无法站在阳光下 | 名正言顺的爱人 |
| 结局 | 悲剧 | 完美 |

### 日常功能

| 场景 | 功能 |
|------|------|
| 暗恋心理 | 让读者爱上白露，建立情感基础 |
| 胖子插科打诨 | 轻松调剂，避免全程黑暗 |
| 学校日常 | 制造"正常生活"反差感 |
| 考试/运动会 | 展现男主"普通人"一面 |
| 王子的存在 | 衬托男主命运的悲凉 |

## 经典日常场景示例

放学时分：王子站在校门口等白露，手里拿着三分糖加椰果温的奶茶。白露出来他挥挥手，"今天怎么这么晚？""啊，王老师找我有点事……"白露接过奶茶笑得眼睛弯弯。

这一幕被站在远处的林奕看到了。他手里也有一杯奶茶——也是按白露口味买的——但买的时候手抖了一下，糖放多了。他喝了一口，苦的。不是糖放多的苦，是别的什么。

他把奶茶扔进了垃圾桶，转身走了。

**这就是林奕和王子最大的区别：王子得到白露是因为他本来就"应该有"；林奕暗恋白露是因为他"不配"。**

## 写作原则

- 每个日常场景不超过3-5章就出现一次新的"不对劲"
- 战斗开始时毫不犹豫，日常戛然而止
- 每个场景必须有功能：揭示角色性格、关系变化、或埋伏笔
