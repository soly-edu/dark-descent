## 恢复类

### 恶魔番茄（普通）
- 里世界农场采集，暗红色比普通番茄大两倍，有血管纹路
- 效果：恢复少量体力、充饥1-2天
- 副作用：难吃有血腥味，吃多做噩梦

### 夜目草（普通）
- 里世界阴暗处采集，深绿细长，黑暗中发微弱绿光
- 效果：食用后30分钟黑暗中可视50米，对半透明生物有效
- 副作用：强光短暂失明，效力结束后极度疲劳

### 止血藤（普通）
- 绞心藤掉落，淡绿色细长藤蔓
- 效果：外敷快速止血、促进伤口愈合、缓解疼痛
- 副作用：伤口愈合留疤，对中毒伤口减半

### 解毒苔藓（普通）
- 矿脉附近采集，灰绿色苔藓有土腥味
- 效果：解无面鼠剧毒，缓解中毒症状
- 副作用：口感极差，可能导致呕吐

### 灵魂花（传说）
- 深渊最底层采集或镜的礼物，半透明花，颜色因灵魂而异
- 效果：恢复灵魂厚度5-10%，缓解灵魂磨损
- 副作用：可能被花瓣中的记忆冲击，用多产生灵魂依赖
- 备注：林奕只在生死关头使用

### 意志坚定剂（稀有）
- 配方：灵魂花×1 + 夜目草×2 + 荧光苔×3 + 水核×1
- 效果：10分钟内抵抗精神攻击（窃语者、疲童有效）
- 副作用：效力结束后极度疲惫，可能产生幻觉，不能连续使用

### 复活加速剂（传说）
- 只能在镜的工坊制作
- 配方：灵魂矿×1 + 镜银矿×1 + 契约之血50ml + 深渊之水100ml
- 效果：复活时间减半（3-5分钟→1.5-2.5分钟），减少复活后虚弱
- 代价：消耗10%灵魂厚度，使用后有短暂的"镜的视野"

## 强化类

### 咒血沸腾剂（稀有）
- 配方：沸血50ml + 契约之血20ml + 深渊铁矿×2
- 效果：10分钟内攻击附带高热，可切开黑曜石装甲
- 代价：手掌烫伤，使用后虚弱，一天只能用一次

### 剧痛刺激剂（稀有）
- 配方：无面鼠毒牙×2 + 暴食之胃强酸腺×1 + 契约之血10ml
- 效果：感官极度敏锐，可被动看到3秒后未来，反应速度+100%
- 代价：极度疼痛，效力结束后昏迷，可能永久感官损伤

### 影子融合剂（传说）
- 配方：暗影精华×3 + 虚空结晶×1 + 契约之血50ml
- 效果：融入阴影完全隐形10分钟，可短距离穿墙
- 代价：极度疲惫，可能"困在阴影中"

## 特殊类

### 契约透支剂（传说）
- 只能在镜的工坊制作
- 配方：契约之血200ml + 灵魂矿×2 + 镜银矿×1
- 效果：无视契约限制强行使用能力，可连续复活不消耗代价
- 代价：消耗30%灵魂厚度，可能触发契约崩溃
