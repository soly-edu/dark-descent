# 场景: `缝隙空间`

## 氛围卡

### 林奕视角
脚下的地面碎了。不是"裂开"，是像糖壳一样碎成粉末。他往前冲——里世界一侧的暗红光越来越近，空气已经从冰凉变成了刺痛。他回头看了一眼。透过半透明的表世界侧墙壁，看到白露站在走廊里，眼神放空，嘴角还挂着刚才和同学说话的弧度。她在发呆。她不知道。他转身，跑向暗红那一侧。墙壁在收缩。他没有时间犹豫。

### 白露视角（弹回瞬间）
她感觉自己在被什么力量"挤"——像穿过一道太窄的门，全身每一寸皮肤都被同时压缩。表世界的光从她身后涌进来，温暖的、正常的、属于她的世界。她不知道自己刚才"消失"了多久。也许一秒。也许更久。手心有点冷。她低头看了一眼——指尖有细微的灰色粉末，像灰烬。她以为是粉笔灰，擦掉了。

### 氛围卡（纯空间）
两条影子。每一盏灯都投下两道——一道偏暖，一道偏冷。地面在碎裂，像走在即将塌陷的薄冰上。两侧的墙壁是两个世界的切面：左边是教室、日光灯、同学们模糊的笑声；右边是灰烬、暗红、远处嘶哑的嚎叫。走廊在缩短。空气在被挤压。每一次呼吸都比上一次更浅。倒计时不在时钟上——它写在正在逼近的墙壁上。

## 氛围关键词
- 双重倒影 / 薄冰碎裂 / 冰水呼吸 / 墙壁挤压 / 两个世界同时可见
- 核心张力：你必须选——回去是安全的日常，往前是必死的战斗。但你不往前，她就会死

## 叙事功能标注
- 抉择空间：每次穿越缝隙都是一次"自愿赴死"的确认
- 视觉奇观：同时看到两个世界的切面是本作独有的视觉记忆点
- 节奏功能：缝隙=日常与战斗的硬切过渡，不需要铺垫，穿越即切换
- 白露指尖的灰烬：前期她不会在意，后期她开始收集——这就是觉醒的起点
