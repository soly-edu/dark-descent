# 场景: `穹顶空间`

## 氛围卡

### 林奕视角
他站在黑色镜面上，看到自己的倒影——不，那不是倒影。倒影在看着他。穹顶在头顶脉动，每一下都像有什么巨大的东西在翻身。镜灵从地面的裂缝里升起来，透明的身体折着冷白色的光，像一盏没有温度的灯。他不想来这里，每次来都意味着契约又添了新条款。他低头看自己的手——镜面上的倒影比他慢半秒才动。他不知道那是延迟，还是另一个自己在试探。

### 镜灵视角
他（它）从裂缝中凝视上方的人形。契约载体的灵魂比上次更暗了——不是被污染，是被磨损，像一把用了太久的刀，刃口还是锋利的，但钢脊已经出现疲劳纹。穹顶又裂了三条。叹息之壁的投影越来越脆弱。主人不会满意。主人从来不会满意。

### 氛围卡（无角色视角——纯环境）
穹顶脉动。暗红光在裂纹中游走，像血管里的血在倒流。镜面地面安静得像坟墓——不，比坟墓更安静，坟墓至少有虫。这里什么都没有。连时间的流逝感都被吃掉了。站在这里的一分钟和一小时没有区别，只有穹顶的脉动在标记"还活着"。

## 氛围关键词
- 冷白光 / 黑色镜面 / 暗红脉动 / 无声心跳 / 存在侵蚀
- 核心张力：极致的空旷与极致的被注视感——你以为四下无人，但穹顶的每一道裂纹都是一只眼睛

## 叙事功能标注
- 命运空间：这里不发生战斗，只发生"宣判"
- 镜灵=裁判，穹顶=法庭，镜面=真相（倒影延迟暗示林奕的自我正在分裂）
- 适合作为节奏调节点——战斗后的冷却、契约条款的揭示、内心独白的触发
- 穹顶裂纹数量=全局危机进度条，后期裂纹密布时氛围应转为紧迫
