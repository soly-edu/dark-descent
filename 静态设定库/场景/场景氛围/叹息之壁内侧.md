# 场景: `叹息之壁内侧`

## 氛围卡

### 林奕视角
抬头。金色纹路从脚边一直延伸到看不见的天顶，像一整片竖起来的天空在燃烧。壁面在嗡鸣，那种低沉的、像铜磬余音一样的震动从脚底传上来——不是通过灰烬，是直接穿透骨头。他站在墙根，脚下的地面和远处荒原没有任何区别，冰冷、粗糙、灰烬粘在鞋底。壁面的金色光打在他身上，影子被拉得很长，投在灰烬地面上像一道裂缝。他不信任这道光。上一次他站在这里，壁面裂开了一道缝，然后白露的灵魂像被磁铁吸住一样飘了进去，而他不得不跟着跳进黑暗里。他抬头看壁面。纹路很完整。今天不会再开门了。大概。远处有东西在灰烬里拖行。它贴着墙根走，和金色壁面只隔一步——但它不碰。什么都不敢碰。

### 白露视角（半梦态，靠近壁面时）
暖。她本能地靠近金色光壁，像飞蛾——不，比飞蛾更笃定，她是被叫回去的。壁面的纹路在她靠近时流速加快，像心脏跳得更快。她的光和壁面的光融为一体，有那么一瞬间她觉得自己属于这里——不是"被保护"，是"回家"。但她不知道为什么想哭。脚下是灰烬，不是她想踩的东西。她记得——不对，她不记得了——脚下应该有什么别的，白色的、温暖的……但灰烬硌着她的脚，冷的，像踩在骨头渣上。

### 氛围卡（纯环境——裂纹出现时）
壁面在呼吸。金色纹路一涨一缩，像某种不可名状的巨兽在休眠——而这只是它无限身躯的极小一段。然后——嘶。一条比头发还细的暗线从壁面中心蔓延开来。纹路在暗线两侧减速、堆积、扭曲，像水流绕过石头。暗线在变宽。不是裂开——是"被从另一侧推开"。里世界的暗红光从裂缝里挤进来，和金色纹路碰撞的地方发出刺耳的电磁噪音。壁面脚下的灰烬被两种光的冲突搅起，在半空中旋转——一半金色一半暗红，像两种血在混合。

### 氛围卡（纯环境——仰视巨墙）
站在墙根仰头，金色纹路像瀑布倒流——从地面升向天空，越升越细，越升越密，最终消失在目力无法分辨的极远高处。你不知道它有多高。你知道你永远爬不上去。壁面的嗡鸣在高处变得不同——不是更轻，是更"厚"，像无数层声音叠在一起。偶尔纹路会在极高处闪一下，像闪电，但没有雷声——那只是法则在重组自己。你感到渺小。不是"我很小"的渺小，是"这面墙在我存在之前就已经在这里了，在我消失之后它还会在这里"的渺小。

## 氛围关键词
- 金色流光 / 灰烬墙根 / 铜磬余音 / 裂纹嘶鸣 / 无边威压
- 核心张力：壮美与敌意共存——壁面令人敬畏，但脚下就是荒原；它在保护你，但它也在困住你；它的每一次"开门"都是一次温柔的绑架

## 叙事功能标注
- 秩序之美的视觉锚点：金色流光是全作最"美"的视觉元素，适合作为悲剧美学的核心意象
- 壮观与威压：壁面的无限延伸本身即是一种压迫——人在这面墙面前，渺小到近乎不存在，这种尺度感强化了"命运不可违抗"的主题
- 保护的暴力性：叹息之壁的保护=强制——它把白露弹回表世界不管她愿不愿意
- 裂纹=倒计时：每次壁面状态变化都是剧情推进的物理信号
- 灰烬地面=真实的提醒：壁面再美，脚下仍是荒原。金色光照不暖灰烬，秩序护不了墙根——人始终站在危险里
- 适合与穹顶空间交叉叙事——穹顶裂纹（里世界深处）和壁面裂纹（屏障本体）是同一件事的两面
