# 场景: `叹息之壁内侧`

## 氛围卡

### 林奕视角
金色。到处都是金色。壁面上的纹路像血管一样在流动，无声地嗡鸣。他站在白沙上，脚底是温暖的——在里世界，这是唯一让他脚底觉得暖的地方。他不信任这份温暖。上一次他站在这里，壁面裂开了一道缝，然后白露的灵魂像被磁铁吸住一样飘了进去，而他不得不跟着跳进黑暗里。他抬头看壁面。纹路很完整。今天不会再开门了。大概。

### 白露视角（半梦态，靠近壁面时）
暖。她本能地靠近金色光壁，像飞蛾——不，比飞蛾更笃定，她是被叫回去的。壁面的纹路在她靠近时流速加快，像心脏跳得更快。她的光和壁面的光融为一体，有那么一瞬间她觉得自己属于这里——不是"被保护"，是"回家"。但她不知道为什么想哭。

### 氛围卡（纯环境——裂纹出现时）
壁面在呼吸。金色纹路一涨一缩，像某种巨大的海洋生物在休眠。然后——嘶。一条比头发还细的暗线从壁面中心蔓延开来。纹路在暗线两侧减速、堆积、扭曲，像水流绕过石头。暗线在变宽。不是裂开——是"被从另一侧推开"。里世界的暗红光从裂缝里挤进来，和金色纹路碰撞的地方发出刺耳的电磁噪音。白沙在裂缝下方变成灰色。

## 氛围关键词
- 金色流光 / 白沙温热 / 铜磬余音 / 裂纹嘶鸣 / 净化边界
- 核心张力：温暖与窒息共存——壁面在保护你，但它也在困住你；它的每一次"开门"都是一次温柔的绑架

## 叙事功能标注
- 秩序之美的视觉锚点：金色流光是全作最"美"的视觉元素，适合作为悲剧美学的核心意象
- 保护的暴力性：叹息之壁的保护=强制——它把白露弹回表世界不管她愿不愿意
- 裂纹=倒计时：每次壁面状态变化都是剧情推进的物理信号
- 适合与穹顶空间交叉叙事——穹顶裂纹（里世界深处）和壁面裂纹（屏障本体）是同一件事的两面
