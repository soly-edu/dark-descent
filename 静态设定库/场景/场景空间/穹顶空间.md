# 场景空间: `穹顶空间`

## 物理属性

- **空间布局**: 里世界最深处的半封闭区域。巨大的穹顶悬浮在虚空中，材质像凝固的黑色玻璃，表面有无数裂纹，裂纹里渗出暗红色微光——像一只正在坏死的巨大眼球。穹顶之下是平坦的黑色镜面地面，倒映出穹顶的裂纹，分不清上下。没有墙壁，四周是无底的黑暗深渊，站在边缘往下看会看到极远处有暗红色光点在移动——那是更低层的里世界原住民。
- **光源类型/强度**:
  - 穹顶裂纹：暗红微光，像快要熄灭的余烬，每隔几秒脉动一次（与"远处心脏"同频）
  - 镜面地面：不发光，但反射穹顶裂纹的红光，形成上下对称的视觉
  - 镜灵出现时：地面裂缝中涌出冷白色光，温度骤降
- **材质触感**:
  - 黑色镜面地面：冰到刺骨，像踩在零下三十度的钢板上，脚底迅速失去知觉
  - 穹顶表面（若触及）：温热、微颤，像触摸巨大生物的皮肤
  - 边缘虚空：伸手探入深渊，指尖像被细密针扎——不是痛，是"存在感被侵蚀"的信号
- **声源**:
  - 穹顶脉动：低沉的"嗡——"，像地壳深处的共鸣，每脉动一次胸腔跟着震动
  - 镜面地面：脚步声被完全吸收，踩上去无声——但心跳声会被放大，像有人在耳边用听诊器
  - 虚空深渊：偶尔传来极遥远的嚎叫，经过无限距离的衰减变成了模糊的呜咽
- **气味**:
  - 主调：冷+旧金属味（像舔铁栏杆），没有有机物的气味
  - 镜灵出现时：臭氧味（像暴雨前的空气），电离感刺鼻
  - 极深处：隐约的甜腥——那是飨食之主的"呼吸"渗透上来的味道

## 特殊环境效果

| 现象 | 描述 |
|------|------|
| 上下倒置感 | 镜面地面完美反射穹顶，初次进入者会失去方向感，无法分辨哪边是天哪边是地 |
| 存在侵蚀 | 长时间停留（>10分钟），四肢末端开始发麻，像灵魂在从指尖脚尖流失 |
| 回声陷阱 | 大声说话不会产生回声，但低语会被无限延伸，变成数十秒后的遥远回音 |

## 叙事功能标注

- 适合场景类型：启示、对峙、命运宣判
- 叙事功能：
  - 飨食之主的"前厅"——他本人不会出现在这里，但他的意志渗透在穹顶的脉动中
  - 镜灵的驻守空间，契约条款的传达场所
  - 林奕每次升级后可能"坠入"此空间接受新的契约条件
  - 穹顶裂纹=叹息之壁受损的投射——裂纹越多，叹息之壁越脆弱
- 核心隐喻：穹顶是笼子的盖子——你以为在最深处，其实它一直在你头顶
