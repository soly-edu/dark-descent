# 场景空间: `里世界荒原`

## 物理属性

- **空间布局**: 表世界的扭曲镜像——校园的位置是一片灰烬覆盖的平原，教学楼变成一排倾斜的黑色石柱，操场是龟裂的干涸河床。没有地平线，远处被暗红色的雾墙吞没，越靠近雾墙空气越稀薄。地面偶尔塌陷，露出下面翻涌的黑色泥浆。
- **光源类型/强度**:
  - 天空：暗红+铁灰交替的穹顶，没有太阳，光从四面八方均匀压下来，像身处一个巨大的内腔
  - 阴影区：石柱背面完全无光，黑到伸手不见五指
  - 无垢之光：白露灵魂散发的柔和白光，半径3-5米，是荒原上唯一的暖色光源
- **材质触感**:
  - 灰烬地面：踩上去像踩炭粉，细密、干燥，脚底传来微微的灼热
  - 黑色石柱：表面有黏液渗出，冰凉滑腻，手指划过会留下白色痕迹（逆化力场正在腐蚀皮肤角质层）
  - 龟裂地面：裂缝边缘锋利如玻璃，颜色由外灰内黑
- **声源**:
  - 风声：不存在。荒原没有风，但空气会"震颤"——像远处有巨大心脏在跳，低频嗡鸣穿透胸腔
  - 怪物：灰烬级的嘶哑爪刮声（指甲划黑板×100）、黑曜级的沉重足音（地面跟着颤）
  - 凝固的寂静：怪物未出现时的荒原比死更安静，安静到能听见自己血管里血液流动的声音
- **气味**:
  - 主调：铁锈+焦糊+腐败甜腻（像腐烂的水果泡在血水里）
  - 战斗区：硫磺味飙升，混着骨头烧焦的刺鼻
  - 无垢之光附近：白光范围内气味会被净化，闻到干净的冷——像冬天深呼吸时鼻腔的冰凉

## 逆化力场环境效果

| 表世界物品 | 荒原中的命运 |
|-----------|-------------|
| 手机/电子设备 | 3秒内屏幕龟裂冒烟，5秒化为飞灰 |
| 合成纤维校服 | 缓慢碳化，2分钟变脆碎裂（但校服是林奕的形态锚点，他会用契约之力维持） |
| 金属拉链/扣子 | 发红氧化，10秒掉渣（林奕战前会本能地扣紧外套，拉链是他每次复活后确认"还在"的触觉锚点） |
| 纸张/笔 | 瞬间碳化 |
| 玻璃 | 5秒内从透明变浑浊，碎裂成黑色粉末 |

## 叙事功能标注

- 适合场景类型：战斗、绝望、孤注一掷
- 叙事功能：
  - 荒原是林奕的主战场，日常的校园在这里变成死亡竞技场
  - 无垢之光是荒原中唯一的"安全区"和视觉焦点——所有战斗围绕白露的灵魂展开
  - 暗红雾墙=未知的恐惧边界，靠近意味着更强的怪物
  - 龟裂地面=环境陷阱，战斗中踏空意味着掉入黑泥
- 核心反差：表世界的操场是笑声和篮球声，里世界的同一片地是灰烬和嘶吼
