# 底层机制: `[#机制:时间线]`
- **绝对限制**: 故事时间线严格遵循十年前→十年沉睡→青春期觉醒→改造期→吸收期的顺序，不可打乱
- **绕过条件**: 无
- **作用范围**: 林奕、白露、飨食之主、契约体系、心蚀四阶段

---


## 第一阶段：改造期（1-100章）

### 第一章开始

```
恶魔出现 → 拉入里世界 → 逆化力场武器锈蚀 → 林奕被杀
→ 复活启动 → 释放飨食之主气息驱退恶魔
→ 男女主不知情（"好像晕过去了又醒了"）
→ 只有镜知道
```

### 改造期的成长

| 阶段 | 章节 | 战斗方式 | 林奕状态 |
|------|------|---------|---------|
| 纯逃跑期 | 1-20章 | 腿比脑子快，目标活命 | 极度恐惧 |
| 被动挨打期 | 20-40章 | 发现死亡后复活，恐惧变底气 | 开始适应 |
| 道具期 | 40-70章 | 表世界道具（钢筋、手术刀）+ 死亡刻印学习 | 尝试反击 |
| 素材武器期 | 70-100章 | 里世界素材制作临时武器 | 能击退灰烬级 |

### 改造期的代价

```
每次死亡 → 镜灵缝合灵魂 + 改造肉体
↓
体温下降、味觉变淡、记忆模糊
↓
白露只感觉"林奕最近怪怪的"
胖子只感觉"林奕身上有血腥味"
```

### 改造完成（~100章）

```
肉体改造完成 → 可以承受吸收
↓
镜灵赠予契约武器（怨骨·初刃）
↓
吸收能力解锁
```

## 第二阶段：吸收期（100-300章）

### 首次吸收（100-120章）

```
林奕用契约武器击杀灰烬级
↓
吸收意外发生
↓
感受到力量涌入
↓
不知道代价，只以为"武器很强"
```

### 白露第一阶段（心蚀0-25%）

```
林奕击杀灰烬级 → 心蚀渐进积累
↓
白露频繁做噩梦
无端悲伤或恐惧
性格从阳光变敏感
↓
向王皓掩饰疲惫
```

### 节点1：首次越级击杀黑曜级（~120-150章）

```
惨烈一战 → 林奕首次击杀黑曜级
↓
吸收量骤增 → 心蚀从25%跳至50%
↓
白露进入第二阶段
↓
表世界色彩褪色、食物无味、闻到血腥味
```

### 中期发展（150-200章）

```
胖子第一次撞破真相 → 镜态度转变
继续战斗 → 白露第二阶段表现持续
契约代价显现（味觉、记忆、体温丧失）
```

---

## 第三阶段：觉醒期（200-300章）

### 节点2：心蚀50%→75%（~200-250章）

```
待定事件 → 白露感知从模糊变清醒
↓
幻痛共鸣开始
↓
白露进入第三阶段
```

### 后期发展（250-300章）

```
白露隐约感知 → 镜完全揭露身份
幻痛共鸣加剧
契约真相逐渐明朗
```

---

## 第四阶段：终局（300-500章）

### 节点3：深渊觉醒之战（~300-350章）

```
灾厄级怪物出现
↓
林奕连续死亡、超频吸收
↓
心蚀逼近100%
↓
白露进入第四阶段 → 完全清醒
```

### 致命一击（~400-450章）

```
白露看清一切真相
↓
将痛苦、愤怒、绝望积累到极点
↓
说出那句话："为什么非要救我，只是因为你自己的私欲！"
↓
契约断裂 → 林奕真死
↓
白露目睹死亡 → 极性反转 → 成为悖论之钥
```

### 终局（450-500章）

```
飨食之主降临 → 叹息之壁碎裂 → 里世界涌入表世界
```

### 里世界结局（神明盲区）

```
镜收集林奕灵魂碎片
用千年偷来的记忆重建永恒黑暗之家
→ 林奕与镜灵以灵魂形态永远相拥
→ 表世界：男主死亡，故事结束
```

## 心蚀阶段与章节对照

| 心蚀阶段 | 程度 | 触发事件 | 章节 |
|---------|------|---------|------|
| 第一阶段·涟漪 | 0-25% | 击杀灰烬级，渐进积累 | 100-120章 |
| 第二阶段·侵蚀 | 25-50% | 首次越级击杀黑曜级 | ~120-150章 |
| 第三阶段·倒影 | 50-75% | 节点2事件（待定） | ~200-250章 |
| 第四阶段·极暗 | 75-100% | 致命一击+目睹死亡 | ~400-450章 |
