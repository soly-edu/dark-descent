# 底层机制: `[#机制:信息暴露节奏]`
- **绝对限制**: 各角色对里世界真相的了解必须严格按章节递进，前中期白露绝对不能得知真相
- **绕过条件**: 无
- **作用范围**: 林奕、白露、王皓、胖子、镜灵

## 对林奕

| 章节 | 暴露内容 | 程度 |
|------|----------|------|
| 1-30章 | 知道自己能快速愈合（死亡复活后） | 50% |
| 30-100章 | 知道有"东西"在追白露 | 60% |
| 50-150章 | 镜开始暗示"愈合"不正常 | 70% |
| 100-200章 | 知道有"契约"存在 | 80% |
| 150-250章 | 知道"契约"的代价 | 90% |
| 250-350章 | 知道契约的真正目的 | 95% |
| 350-500章 | 知道全部真相 | 100% |

## 对白露

| 章节 | 暴露内容 | 程度 |
|------|----------|------|
| 1-100章 | 只知道"林奕很奇怪" | 10% |
| 100-200章 | 偶尔感觉"危险"但不知道为什么 | 25% |
| 200-300章 | 隐约知道有"东西"在追她 | 40% |
| 300-400章 | 知道里世界、恶魔的存在 | 60% |
| 400-500章 | 知道全部真相 | 100% |

## 对胖子

| 章节 | 暴露内容 | 程度 |
|------|----------|------|
| 1-100章 | 只觉得"林奕最近不对劲" | 10% |
| 100-150章 | 第一次撞破真相（看到重塑） | 50% |
| 150-200章 | 挣扎与接受 | 70% |
| 200-300章 | 了解部分真相 | 85% |
| 300-500章 | 知道全部 | 100% |

## 对镜灵

| 章节 | 暴露内容 | 程度 |
|------|----------|------|
| 5-30章 | 偶尔"幻觉"中出现 | 0% |
| 30-100章 | 自称"缝补者" | 10% |
| 100-200章 | 开始问男主问题 | 20% |
| 150-250章 | 暗示自己的过去 | 40% |
| 250-350章 | 揭露部分真相 | 60% |
| 350-450章 | 完全揭露身份 | 90% |
| 450-500章 | 最终抉择 | 100% |

## 暴露原则

- **白露**：前中期绝对不能了解里世界、男主真实身份、作战过程。只能后期逐渐接触。
- **胖子**：前期只是感觉奇怪不追问。中后期被迫撞破。
- **镜**：前期接触极少态度冷漠，中后期逐渐转变。
- **王子**：前期完全不知情，作为"对照组"衬托男主悲凉命运。
