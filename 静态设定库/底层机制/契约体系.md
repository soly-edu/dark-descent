# 底层机制: `[#机制:契约体系]`
- **绝对限制**: 林奕能够一次次从死亡中复活，但每次都要支付"买路钱"——作为人类的"未来"与"感官"
- **绕过条件**: 无

## 复活机制：魂引与代偿

### 魂引

- 里世界，死亡是一条不可逆的黑色河流
- 林奕能够逆流而上、重聚肉身，是因为他的灵魂通过**"魂引"**与白露的灵魂（无垢之魂）相连
- 十年前白露的"无垢之光"，正是这根魂引的起点
- 魂引 = 连接林奕灵魂与白露灵魂的无形纽带，不是"手上拿着"

### 气息信号（恶魔探测器）

**核心机制**：林奕身上携带的飨食之主力量印记，会散发出微弱的"信号"，恶魔将其视为"猎物标记"而聚集过来。

```
林奕契约力量苏醒（青春期）
    ↓
身上携带飨食之主的力量印记
    ↓
平时持续散发微弱的气息
    ↓
恶魔将这股气息识别为"飨食之主的猎物标记"
    ↓
恶魔被吸引聚集到林奕（和白露）所在区域
```

**与"威压驱散"的关系**（重要澄清）：
| 机制 | 触发条件 | 作用 | 性质 |
|------|----------|------|------|
| **气息信号** | 平时持续散发 | 吸引恶魔聚集 | 淡淡的"猎物标记" |
| **威压释放** | 死亡/复活瞬间 | 驱散当前区域的恶魔 | 恐怖的"王者压制" |

- 气息和威压是**两种不同的力量表现形式**，不冲突
- 气息 = 标记（平时）→ 吸引
- 威压 = 压制（死亡瞬间）→ 驱散
- 恶魔被气息"吸引"是因为把它们当作飨食之主的猎物
- 但当威压真正释放时，恶魔会恐惧逃跑，因为那是飨食之主的真正力量

详见 [#机制:双轨世界] 的"十年空白期"解释。

### 缝隙形成机制（核心触发）

详见 [#机制:双轨世界] 的"缝隙形成机制"。

**简化说明**：

```
叹息之壁感知到"无垢之魂+魂引连接飨食之主印记"
    ↓
叹息之壁误判为"一体" → 启动陷阱机制
    ↓
叹息之壁打开大门，吸入无垢之魂和林奕
    ↓
林奕的气息吸引恶魔聚集 → 腐蚀叹息之壁 → 缝隙扩大
```

### 代偿

- 想要逆流，就必须留下"买路钱"
- 林奕的十年暗恋不足以支付这种天价，他支付的是作为人类的"未来"与"感官"
- 每一次重塑残躯，都要被剥夺一部分"生而为人"的特质：一小段温暖的记忆、对甜味的感知、指尖的触觉，甚至是流泪的能力
- 最终导致他越来越像一个冰冷的怪物

## 血肉结界

飨食之主在契约里埋下的隐秘法则：

### 机制

- 每次林奕被恶魔杀死，他肉体崩解和灵魂重塑的瞬间，会释放出属于飨食之主的一丝恐怖威压
- 这股威压会在白露周围形成一个短暂的绝对安全区，将残存的低级恶魔强行驱逐回里世界
- **只要林奕还在死，白露就绝对安全**

### 表现机制（白露感知不到，但实际保护生效）

```
林奕在里世界被怪物杀死
↓
契约触发：复活启动
↓
重塑过程：约3-5分钟（里世界时间）
↓
释放飨食之主的威压
↓
威压覆盖半径约50米，形成"安全区"
↓
恶魔被驱退（不是杀死，只是赶走）
↓
威压消散后，恶魔可能重新聚集
↓
白露感知：无论在里世界还是提前返回表世界，都感知不到林奕的死亡
         只感觉"有什么消失了又回来"或"发了会儿呆"
```

### 威压与缝隙关闭的关系

详见 [#机制:双轨世界] 的"白露弹回机制"。

**简化流程**：
```
林奕被恶魔杀死
    ↓
威压释放 → 恶魔被驱散
    ↓
腐蚀消失 → 叹息之壁"伤口"愈合
    ↓
通道畅通 → 白露可以正常返回
    ↓
白露被弹回表世界（安全状态）
    ↓
林奕复活 → 继续清理残余恶魔
    ↓
所有恶魔清理完毕 → 缝隙关闭 → 林奕返回表世界
```

**威压的作用**：
- 不是"永久"驱散，而是提供一个**时间窗口**
- 在这个窗口内，叹息之壁的"伤口"愈合
- 白露可以正常通过畅通的通道返回
- 林奕继续清理残余恶魔，防止威压消散后恶魔回来

**前期战斗失败的逻辑闭环**：
1. 林奕被怪物杀死 → 威压释放 → 恶魔暂时被驱散
2. 腐蚀消失 → 叹息之壁通道畅通 → 白露被正常弹回
3. 林奕复活 → 继续面对残余恶魔
4. 如果林奕能在威压消散前清理完恶魔 → 缝隙关闭，两人安全返回
5. 如果林奕失败 → 白露已安全，林奕独自面对威胁（等待下一次复活）

**林奕返回的保底机制**：
- 详见 [#机制:双轨世界] 的"契约保底机制"模块
- 魂引 = 连接林奕灵魂与白露灵魂的无形纽带
- 即使缝隙完全关闭，魂引依然有效
- 如果林奕未能在缝隙关闭前返回，契约会强制把他"拉"回白露身边

## 里世界探索机制

林奕可以选择主动留在里世界，利用时间差进行探索、采集、变强。

### 核心功能

| 功能 | 说明 |
|------|------|
| **采集素材** | 吸收怪物残余能量、收集里世界稀有材料 |
| **利用怪物** | 吸收死亡怪物的暗黑能量，转化为自身力量 |
| **探索遗迹** | 发掘里世界隐藏区域、获取特殊道具或能力碎片 |
| **刷怪变强** | 重复遭遇战，积累战斗经验 |

### 时差机制

| 里世界主观时间 | 表世界现实时间 | 可进行活动 |
|----------------|----------------|------------|
| 1-2小时 | ~5秒 | 简单搜刮、吸收残余 |
| 3-5小时 | ~15秒 | 小范围探索、采集 |
| 10+小时 | ~30秒-1分钟 | 大型探索、深入遗迹、获取重要道具 |

**时差比例**：表世界1秒 ≈ 里世界30分钟（1:1800）

### 代价机制

林奕每次选择留在里世界，都需要消耗"人性代偿"作为代价。

| 区域 | 探索 | 死亡复活 |
|------|------|----------|
| 正常区域 | 消耗人性代偿 | 消耗人性代偿 + 时间（复活3-5分钟） |
| 安全结界内 | **不消耗人性代偿** | 消耗人性代偿 + 时间（复活3-5分钟） |

**死亡复活本身也有代价**：
- 复活需要支付"买路钱"（人性代偿）
- 复活过程需要3-5分钟（里世界时间），期间无法行动
- 反复死亡只会累积更多代价，无法规避正常探索的代偿

**安全结界内不消耗代偿**：
- 安全结界 = 林奕死亡时释放威压形成的短暂安全区
- 威压庇护范围内，契约机制暂停运作
- 林奕在安全结界内探索不消耗人性代偿

**延迟程度与代偿消耗**：

| 延迟程度 | 里世界时间 | 代偿消耗 | 说明 |
|----------|------------|----------|------|
| 短延迟 | 1-2小时 | 少量碎片 | 简单探索 |
| 中延迟 | 3-5小时 | 中等碎片 | 小范围探索 |
| 长延迟 | 10+小时 | 大量碎片 | 大型探索、遗迹 |

**渐进式揭露**：
- **早期**：林奕只觉得"有点不舒服"，以为是里世界的环境影响，不会深究
- **中期**：多次延迟后，开始察觉异常（头疼、反应变慢、偶尔遗忘小事），但可能归咎于学业压力
- **后期**：通过剧情揭露真相——这些异常是"留在里世界"的代价

### 探索流程

```
林奕清理完恶魔
    ↓
缝隙开始加速修复
    ↓
缝隙完全修复完成
    ↓
林奕确认安全，离开缝隙位置
    ↓
向里世界其他区域探索
    ↓
收获：素材、能力、道具...
    ↓
人性代偿代价逐渐累积
    ↓
选择返回方式
    ├─ 常规返回：心中感到"想回去"，契约响应
    └─ 保底返回：人性代偿耗尽，强制撤回
    ↓
返回表世界
```

### 返回机制

| 返回方式 | 触发条件 | 林奕感知 |
|----------|----------|----------|
| **常规返回** | 林奕感到"想回去"时 | "我待得够久了，该回去了" |
| **保底返回** | 人性代偿耗尽 | 身体不适加剧，意识模糊后强制撤回 |

**常规返回**：
- 林奕不需要知道契约机制
- 只是心中产生一种强烈的"回程感"
- 林奕以为是自己的本能反应
- 契约自动响应，将林奕拉回表世界

**保底返回**：
- 人性代偿消耗达到身体极限
- 林奕感到强烈不适（头疼、意识模糊）
- 无法抗拒地被强制撤回表世界
- 林奕以为是"里世界待太久"的副作用

- **时间风险**：表世界时间过长会引起旁人注意（详见 [#机制:双轨世界]）
- **感知风险**：白露可能会察觉"林奕消失"的时间越来越长

**【前期】情况2为主：两人同时返回**

- 成为白露察觉异常的伏笔

## 无垢之魂的双重存在

### 核心设定

```
白露的身体留在表世界（原地发呆）
白露的灵魂进入里世界（无垢之光形态）
```

### 林奕的感知

- 林奕能看到白露的灵魂在里世界中漂浮（一团光芒）
- 林奕能通过魂引感知白露的状态
- 林奕的职责是守护这团光芒，直到战斗结束

## 不可复制的特质：空心症+共生之痕

### 空心症

- 林奕是一个在原生家庭和人际关系中极度缺爱的"空心人"
- 只有胖子一个朋友
- 生命轻如鸿毛，当一束光照进来时，他把整束光当作整个宇宙
- 只有他这种"除了她，我什么都不在乎"的极端偏执狂，才能承载单一魂引的拉扯力

### 共生之痕

- 十年前火灾时，白露的"无垢之魂"渡了一小部分给他，让他成为"窃命者"
- 飨食之主在无数人中选中他，正是闻到了他灵魂深处那丝属于她的味道

## 能力的边界与崩溃

### 灵魂磨损

- 每复活一次，灵魂变薄一分
- 当所有用来当燃料的"多余记忆和人性"被燃烧殆尽时，他就再也无法维持人类理智

### 崩溃的终极条件（逻辑悖论死锁）

```
锚点指令：保护她，让她幸福
现实反馈：我的保护和牺牲，正是让她痛苦绝望（被指责为私欲）的根源
```

当白露喊出"为什么非要救我，只是因为你自己的私欲"——这句话直接抛出致命死锁悖论：
- 对林奕：击碎了他赴死的唯一理由，契约作废，迎来真正的死亡
- 对白露：亲手否定救命恩人，极致的纯洁在极致的懊悔中瞬间黑化
