# 底层机制: `[#机制:无垢之光]`

- **绝对限制**: 白露灵魂的本质，与叹息之壁同源，秩序法则在白露身上的具现
- **绕过条件**: [#机制:心蚀四阶段]（内部渗透而非外部污染）
- **作用范围**: [@角色:白露]

## 本质

**无垢之光**是白露灵魂的**本质**，**无垢之魂**是白露灵魂的**存在形式**。

```
白露的灵魂（存在形式）= 无垢之魂
    ↓
无垢之魂的本质 = 无垢之光
    ↓
无垢之光 = 秩序法则在白露身上的具现
    ↓
无垢之光与叹息之壁的本质同源
```

## 为什么无垢之魂会被吸入里世界？

详见 [#机制:双轨世界] 的"缝隙形成机制"。

**简化说明**：

```
叹息之壁感知到"无垢之魂+魂引连接飨食之主印记"
    ↓
叹息之壁误判为"一体" → 启动陷阱机制
    ↓
叹息之壁打开大门，吸入无垢之魂和林奕
```

**关键点**：无垢之魂与叹息之壁同源，但叹息之壁开门的原因不是"邀请"，而是"陷阱"。

## 核心机制

### 双重存在

```
白露的身体留在表世界（原地发呆）
白露的灵魂进入里世界（无垢之光形态）
```

### 林奕的感知

- 能看到白露的灵魂在里世界中漂浮（一团光芒）
- 能通过 [#机制:契约体系] 的魂引感知白露的状态
- 林奕的职责是守护这团光芒，直到战斗结束

### 保护作用

当里世界怪物触碰到无垢之魂时，触发 [#机制:叹息之壁] 的紧急召回机制。

### 被污染过程

白露的内里被林奕的 [#机制:溢出机制] 逐渐填满、黑化，最终 [#机制:心蚀四阶段] 达到第四阶段·极暗。

## 与叹息之壁的关系

详见 [#机制:叹息之壁]。

**简述**：
- 两者同源于秩序
- 叹息之壁会为无垢之魂"开门"
- 但这也让悖论之钥能够骗过叹息之壁的判定

## 悖论之钥的形成

```
表层 = 无垢之光（秩序的产物）
内里 = 极暗之源（暗黑能量的容器）
    ↓
[#机制:叹息之壁] 对她敞开（因为表层仍是同源之物）
    ↓
[#机制:飨食之主] 降临
```
