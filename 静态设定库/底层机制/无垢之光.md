# 底层机制: `[#机制:无垢之光]`

- **绝对限制**: 白露灵魂的本质，与叹息之壁同源，秩序法则在白露身上的具现
- **绕过条件**: [#机制:心蚀四阶段]（内部渗透而非外部污染）
- **作用范围**: [@角色:白露]

## 本质

无垢之魂是**秩序法则在白露身上的具现**，与叹息之壁**同源于秩序**。

```
叹息之壁 = 秩序法则编织的屏障
无垢之魂 = 秩序法则在白露身上的具现
    ↓
同源共鸣 = 无垢之魂天然被叹息之壁视为"同类"
```

## 为什么无垢之魂可以进入里世界？

普通表世界人类无法进入里世界，因为里世界是反秩序的空间。

但无垢之魂特殊：
- 它与叹息之壁**同源**
- 叹息之壁会为同源之物"开门"
- 这道门就是"缝隙"

```
无垢之魂出现 → 叹息之壁感知到"同源气息"
    ↓
叹息之壁的反应：不是"阻挡"，而是"引导"
    ↓
引导无垢之魂进入里世界的特殊通道：缝隙
```

## 核心机制

### 双重存在

```
白露的身体留在表世界（原地发呆）
白露的灵魂进入里世界（无垢之光形态）
```

### 林奕的感知

- 能看到白露的灵魂在里世界中漂浮（一团光芒）
- 能通过 [#机制:契约体系] 的魂引感知白露的状态
- 林奕的职责是守护这团光芒，直到战斗结束

### 保护作用

当里世界怪物触碰到无垢之魂时，触发 [#机制:叹息之壁] 的紧急召回机制。

### 被污染过程

白露的内里被林奕的 [#机制:溢出机制] 逐渐填满、黑化，最终 [#机制:心蚀四阶段] 达到第四阶段·极暗。

## 与叹息之壁的关系

详见 [#机制:叹息之壁]。

**简述**：
- 两者同源于秩序
- 叹息之壁会为无垢之魂"开门"
- 但这也让悖论之钥能够骗过叹息之壁的判定

## 悖论之钥的形成

```
表层 = 无垢之光（秩序的产物）
内里 = 极暗之源（暗黑能量的容器）
    ↓
[#机制:叹息之壁] 对她敞开（因为表层仍是同源之物）
    ↓
[#机制:飨食之主] 降临
```
