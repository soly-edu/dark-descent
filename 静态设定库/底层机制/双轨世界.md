# 底层机制: `[#机制:双轨世界]`

- **绝对限制**: 表世界与里世界重叠存在，缝隙是唯一的通道入口；里世界时间流速远快于表世界；白露灵魂耐受上限为15-20分钟
- **绕过条件**: 无

## 表世界

- 青春校园、阳光日常的现代都市
- 白露和王皓在此生活
- 人类正常生活的空间

## 里世界（恶魔猎场）

- 隐藏在阴影中的修罗场
- 表面与表世界重叠，但只在"缝隙"出现时才能进入
- 充满反生命、反物质的逆化力场

## 缝隙形成机制（核心触发）

### 形成条件

```
白露出现在某地 → 无垢之魂的气息散发 → 叹息之壁感知到"同源气息"
                                    ↓
                    叹息之壁对无垢之魂的反应："开门"
                                    ↓
                    恶魔被"无垢之光"吸引聚集 → 恶意积累
                                    ↓
                    恶意腐蚀叹息之壁的"门"区域 → 缝隙扩大
```

### 缝隙的本质

缝隙不是"撕裂"出来的，而是叹息之壁对无垢之魂的"反应"。

- 无垢之魂与叹息之壁**同源**
- 叹息之壁会为同源之物"开门"
- 这道门就是缝隙

### 林奕与白露的进入方式区分

| 角色 | 进入方式 | 进入原因 |
|------|----------|----------|
| **白露** | 叹息之壁主动"开门" | 无垢之魂与叹息之壁同源，叹息之壁为同源之物开门 |
| **林奕** | 被动拉入（依附于白露的缝隙） | 契约力量 + 曾死亡 + 被注入无垢之光 |

**关键说明**：
- 叹息之壁只为白露开门
- 林奕不是"自己开门进去"，而是被**强制拉入**白露的缝隙
- 林奕能承受里世界的压力是因为：契约保护 + 复活过 + 有无垢之光的底子
- 林奕的存在与缝隙/白露绑定——白露消失，缝隙关闭，林奕也会被弹回

### 为什么飨食之主不能制造缝隙或通过缝隙？

| 方式 | 原因 | 结果 |
|------|------|------|
| 飨食之主主动制造缝隙 | 缝隙是叹息之壁对无垢之魂的"反应"，不是飨食之主能控制的 | ❌ 不可能 |
| 飨食之主通过缝隙进入表世界 | 飨食之主是里世界最深处的存在，被束缚在那边 | ❌ 不可能 |
| 飨食之主直接触碰表世界 | 存在形式不允许，无法跨越表里世界的界限 | ❌ 不可能 |

**飨食之主的限制**：
- 他是里世界的"原住民"，被锁在自己的领域
- 他无法主动制造缝隙（那是叹息之壁对无垢之魂的反应）
- 他只能等待缝隙自然形成，然后**等待**

### 缝隙与飨食之主的关系

```
飨食之主的困境：
- 无法主动制造缝隙
- 无法穿过叹息之壁
- 无法直接触碰表世界

飨食之主的解决方案：
- 找一个能在表里世界之间活动的"工具"
- 这个工具就是林奕
- 林奕能进入缝隙、杀死恶魔，保护白露
- 而林奕的"保护"行为，恰恰在帮飨食之主雕刻钥匙
```

## 保护机制

```
缝隙形成 → 白露无垢之魂进入里世界（像一团光芒漂浮）
                        ↓
        林奕被强制拉入（依附于白露的缝隙）
                        ↓
        林奕在里世界守护这团光芒
                        ↓
        击杀恶魔 OR 等待缝隙消失
                        ↓
        白露无垢之魂回到身体 → 醒来（以为自己只是走神了一下/做了个短梦）
        林奕从里世界返回 → 假装"刚好在旁边"/"你没事吧？"
```

## 时间差机制

### 核心规则

```
里世界时间和表世界时间流速不同
缝隙越稳定，时间差越小
```

### 时间差比例

| 阶段 | 战斗时长 | 表世界时间 | 比例 | 说明 |
|------|----------|-----------|------|------|
| **前期**（灰烬级） | 30分钟 | **1秒** | 1:1800 | 缝隙极不稳定，时间差极大 |
| **中期**（黑曜级） | 1-2小时 | 30秒-1分钟 | 1:120~1:120 | 缝隙逐渐稳定 |
| **后期**（灾厄级） | 3-5小时 | 3-5分钟 | 1:60 | 缝隙更稳定 |
| **极端**（最终战） | 10+小时 | 10-15分钟 | 1:40 | 缝隙非常稳定 |

### 白露的灵魂耐受上限

- 无论时间差多少，白露灵魂在里世界最多停留 **15-20分钟（主观感受）**
- 超过耐受上限 → 灵魂被自动弹回身体 → 白露"醒来"

## 白露的状态

### 里世界中的白露

- **无垢之魂形态**：一团漂浮在里世界的光芒
- **意识状态**：半梦状态
  - 能看到模糊的画面（林奕战斗的影子）
  - 能感受到情绪（林奕的绝望/坚持）
  - 但不能移动、不能说话、不能互动
- **身体状态**：留在原地，眼神放空，像在"发呆"

### 醒来后的白露

- 以为自己只是"走神"了一下或"做了个梦"
- 梦境内容模糊：感觉有光、有模糊的声音、有危险的感觉
- 以为是正常现象，不会深究
- **后期**：开始做"连续的噩梦"，梦境内容更清晰

## 林奕的行为

### 进入方式

- 白露出现 → 缝隙形成 → 林奕**同时**被拉入里世界
- 不需要主动进入缝隙
- 林奕与缝隙绑定——白露消失，缝隙关闭，林奕也会被弹回

### 战斗原则

1. **优先击杀**：尽可能在白露灵魂耐受期内杀光怪物
2. **守护光芒**：白露的灵魂是核心目标，不能让它被怪物碰到
3. **引导撤离**：如果来不及击杀，带着白露的灵魂撤离危险区域

### 返回机制

| 情况 | 触发条件 | 表世界表现 |
|------|----------|----------|
| **情况1（前期为主）** | 林奕在白露耐受期内击杀所有怪物，缝隙消失 | 两人同时返回，白露以为只是发呆 |
| **情况2（中后期出现）** | 白露灵魂耐受到期，被弹回表世界；林奕继续战斗直到缝隙消失 | 白露先醒，感受到"林奕消失了一会儿" |

### 情况2的伏笔设计

```
【中期·白露提前返回几秒】
白露："你刚才去哪了？我好像没看到你……"
林奕："没有啊，我一直在这里。"
白露："……可能是我眼花了。"

【后期·白露提前返回几十秒】
白露明显感受到林奕"消失"
开始追问，成为察觉真相的关键节点
```

### 返回后

- 两人同时返回时：白露以为只是做了个梦，林奕假装"你刚才走神了一下，没事吧"
- 白露提前返回时：林奕返回后需要解释"刚才去了一下厕所/接了个电话"

## 十年空白期的解释

### 核心设定

`[#剧情事件:十年前闪回序章]`中，契约能力就被赐予了，但处于"沉睡状态"。

### 为什么白露以前没有遭遇怪物？

**关键原因**：林奕的契约力量处于沉睡状态

```
十年前火灾：
- 白露的无垢之光觉醒了（那次火灾本身就是缝隙的雏形）
- 飨食之主闻到了"无垢之光"的味道
- 赐予林奕沉睡的契约能力（单向安排，男主不知情）
    ↓
十年间：
- 林奕的契约力量持续沉睡
- 灵魂沉睡 = 气息微弱
- 叹息之壁感知不到明显的"同源气息"
- 缝隙几乎不会形成
- 恶魔不会聚集到白露身边
    ↓
青春期觉醒（约16-17岁）：
- 契约力量开始苏醒
- 林奕散发的气息变强
- 气息中带有飨食之主的力量（契约的源头）
- 这股气息被叹息之壁感知
- 缝隙开始更容易被腐蚀
- 恶魔开始被吸引到白露身边
```

**简述**：不是白露以前安全，而是林奕沉睡时，他的气息掩盖了白露的无垢之光。当林奕觉醒后，反而"激活"了这个系统。
