# 底层机制: `[#机制:双轨世界]`

- **绝对限制**: 表世界与里世界重叠存在，缝隙是唯一的通道入口；里世界时间流速远快于表世界；白露灵魂耐受上限为15-20分钟
- **绕过条件**: 无

## 表世界

- 青春校园、阳光日常的现代都市
- 白露和王皓在此生活
- 人类正常生活的空间

## 里世界（恶魔猎场）

- 隐藏在阴影中的修罗场
- 表面与表世界重叠，但只在"缝隙"出现时才能进入
- 充满反生命、反物质的逆化力场

## 缝隙形成机制（核心触发）

### 形成条件

```
白露出现在某地 → 无垢之魂的气息散发
                                    ↓
                    林奕的气息散发（契约力量）
                                    ↓
                    叹息之壁感知到"无垢之魂"
                                    ↓
                    同时感知到无垢之魂有"魂引"连接到飨食之主的气息
                                    ↓
                    【关键】叹息之壁误判为"一体" → 启动陷阱机制
                                    ↓
                    叹息之壁打开大门
                                    ↓
                    无垢之魂与林奕被一同"吸入"里世界
                                    ↓
                    林奕的气息吸引恶魔聚集（详见 [#机制:契约体系] 的"气息信号"）
                                    ↓
                    恶魔的恶意腐蚀叹息之壁的"门"区域 → 缝隙扩大
```

**叹息之壁的真实目的（陷阱机制）**：
```
叹息之壁打开大门
    ↓
叹息之壁的计划：将"一体"的两个存在吸入
    ↓
然后分离它们
    ↓
把飨食之主的气息（林奕）留在里世界
    ↓
把无垢之魂（白露）弹回表世界
```

**为何叹息之壁要这么做？**
- 飨食之主是里世界最深处的存在
- 叹息之壁感知到有飨食之主的气息附着在无垢之魂上
- 叹息之壁想要"清除"这个异常 → 把林奕困在里世界

**但契约打破了陷阱**：
- 林奕有契约，可以通过魂引回到表世界
- 所以叹息之壁的"陷阱"没有完全成功

**反复机制**：
- 每次白露出现，叹息之壁都重复这个过程
- 中间被怪物腐蚀打断
- 叹息之壁优先修复缝隙并保证无垢之魂安全

**白露以前的经历**：
- 林奕契约沉睡 → 没有气息散发
- 叹息之壁只感知到无垢之魂 → 不会开门
- 白露不会进入里世界 → 不会遭遇怪物

### 恶魔腐蚀的原理

| 要素 | 说明 |
|------|------|
| **腐蚀来源** | 恶魔的恶意 = 里世界对表世界"入侵者"的敌意 |
| **腐蚀本质** | 恶魔靠近叹息之壁时，会释放暗黑能量腐蚀屏障 |
| **腐蚀效果** | "门"被腐蚀后变大 = 缝隙扩大 = 里世界压力增强 |
| **腐蚀结果** | 白露灵魂和林奕被迫卷入更深的里世界 |

**叹息之壁"开门"与"弹回"的关系**（澄清逻辑）：
- "开门" = 叹息之壁感知到异常信号后的响应（邀请无垢之魂进入里世界）
- "弹回" = 叹息之壁感知到"受伤"后的安全防御（保护自己）
- 两个机制针对不同情况，不冲突：
  - 开门：正常响应异常信号
  - 弹回：异常情况下的保护机制

### 缝隙的本质

缝隙不是"撕裂"出来的，而是叹息之壁对无垢之魂的"反应"。

- 无垢之魂与叹息之壁**同源**
- 叹息之壁会为同源之物"开门"
- 这道门就是缝隙

### 林奕与白露的进入方式区分

| 角色 | 进入方式 | 进入原因 |
|------|----------|----------|
| **白露** | 叹息之壁陷阱机制 | 叹息之壁误判一体，吸入里世界 |
| **林奕** | 被叹息之壁"吸入"（因魂引连接） | 魂引让叹息之壁误判为"一体" |

**林奕被吸入的原理**：
```
叹息之壁误判"无垢之魂+魂引连接飨食之主印记"为"一体"
    ↓
叹息之壁打开大门
    ↓
叹息之壁的计划：吸入→分离→困住林奕→弹回白露
    ↓
林奕与白露同时被吸入里世界
```

**林奕为何能被吸入**：
- 魂引让林奕与白露"绑定"在一起
- 叹息之壁误判为"一体"
- 叹息之壁吸入时，把林奕也一起带进去了

**白露以前的经历**：
- 详见"十年空白期的解释"章节
- 以前林奕契约沉睡，无魂引连接
- 叹息之壁只感知到无垢之魂 → 不会误判为"一体" → 不会开门
- 白露不会进入里世界

### 为什么飨食之主不能制造缝隙或通过缝隙？

| 方式 | 原因 | 结果 |
|------|------|------|
| 飨食之主主动制造缝隙 | 缝隙是叹息之壁对无垢之魂的"反应"，不是飨食之主能控制的 | ❌ 不可能 |
| 飨食之主通过缝隙进入表世界 | 飨食之主是里世界最深处的存在，被束缚在那边 | ❌ 不可能 |
| 飨食之主直接触碰表世界 | 存在形式不允许，无法跨越表里世界的界限 | ❌ 不可能 |

**飨食之主的限制**：
- 他是里世界的"原住民"，被锁在自己的领域
- 他无法主动制造缝隙（那是叹息之壁对无垢之魂的反应）
- 他只能等待缝隙自然形成，然后**等待**

### 缝隙与飨食之主的关系

```
飨食之主的困境：
- 无法主动制造缝隙
- 无法穿过叹息之壁
- 无法直接触碰表世界

飨食之主的解决方案：
- 找一个能在表里世界之间活动的"工具"
- 这个工具就是林奕
- 林奕能进入缝隙、杀死恶魔，保护白露
- 而林奕的"保护"行为，恰恰在帮飨食之主雕刻钥匙
```

## 保护机制

```
缝隙形成 → 白露无垢之魂进入里世界（像一团光芒漂浮）
                        ↓
        林奕被强制拉入（依附于白露的缝隙）
                        ↓
        林奕在里世界守护这团光芒
                        ↓
        击杀恶魔 OR 等待缝隙消失
                        ↓
        白露无垢之魂回到身体 → 醒来（以为自己只是走神了一下/做了个短梦）
        林奕从里世界返回 → 假装"刚好在旁边"/"你没事吧？"
```

## 时间差机制

### 核心规则

```
里世界时间和表世界时间流速不同
缝隙越稳定，时间差越小
```

### 时间差比例

| 阶段 | 战斗时长 | 表世界时间 | 比例 | 说明 |
|------|----------|-----------|------|------|
| **前期**（灰烬级） | 30分钟 | **1秒** | 1:1800 | 缝隙极不稳定，时间差极大 |
| **中期**（黑曜级） | 1-2小时 | 30秒-1分钟 | 1:120~1:120 | 缝隙逐渐稳定 |
| **后期**（灾厄级） | 3-5小时 | 3-5分钟 | 1:60 | 缝隙更稳定 |
| **极端**（最终战） | 10+小时 | 10-15分钟 | 1:40 | 缝隙非常稳定 |

### 白露的灵魂耐受上限

- 无论时间差多少，白露灵魂在里世界最多停留 **15-20分钟（主观感受）**
- 超过耐受上限 → 灵魂被自动弹回身体 → 白露"醒来"

## 白露的状态

### 里世界中的白露

- **无垢之魂形态**：一团漂浮在里世界的光芒
- **意识状态**：半梦状态
  - 能看到模糊的画面（林奕战斗的影子）
  - 能感受到情绪（林奕的绝望/坚持）
  - 但不能移动、不能说话、不能互动
- **身体状态**：留在原地，眼神放空，像在"发呆"

### 醒来后的白露

- 以为自己只是"走神"了一下或"做了个梦"
- 梦境内容模糊：感觉有光、有模糊的声音、有危险的感觉
- 以为是正常现象，不会深究
- **后期**：开始做"连续的噩梦"，梦境内容更清晰

## 林奕的行为

### 进入方式

- 白露出现 → 缝隙形成 → 林奕**同时**被拉入里世界
- 不需要主动进入缝隙
- 林奕依靠契约力量在里世界行动，与白露的弹回无直接关联

### 战斗原则

1. **优先击杀**：尽可能在白露灵魂耐受期内杀光怪物
2. **守护光芒**：白露的灵魂是核心目标，不能让它被怪物碰到
3. **引导撤离**：如果来不及击杀，带着白露的灵魂撤离危险区域

### 返回机制

**林奕的返回**：通过**魂引**返回表世界，不是通过缝隙。

**两种情况**：

**情况A：有怪物战斗**
```
林奕清理完恶魔
    ↓
恶魔被驱散（威压或战斗）
    ↓
腐蚀消失 → 叹息之壁开始修复
    ↓
叹息之壁修复完成 → 缝隙关闭
    ↓
叹息之壁将无垢之魂弹回表世界
    ↓
林奕通过魂引返回表世界
```

**情况B：无怪物/怪物被驱散后**
```
恶魔被驱散（高级怪物不会被驱散）
    ↓
腐蚀消失
    ↓
叹息之壁修复完成 → 缝隙关闭
    ↓
叹息之壁将无垢之魂弹回表世界
    ↓
林奕通过魂引返回表世界
```

**高级怪物情况**：
- 高级怪物不会被威压驱散
- 林奕必须击杀所有高级怪物
- 击杀后按情况A/B处理

**林奕返回与白露返回的区别**：
| 角色 | 返回方式 | 返回时机 |
|------|----------|----------|
| **白露** | 被叹息之壁弹回 | 缝隙修复完成后 |
| **林奕** | 通过魂引返回 | 缝隙关闭后，随时可以 |

**威压的作用**：
- 驱散低级怪物
- 加速腐蚀消失 → 加速缝隙关闭 → 白露更快返回

### 白露弹回机制（叹息之壁的安全防御）

**叹息之壁的双重状态**：
```
叹息之壁（正常状态）：
- 允许无垢之魂在表世界与里世界之间通行
- 缝隙 = 为无垢之魂开启的门

叹息之壁（受腐蚀状态）：
- 腐蚀 = 叹息之壁的"伤口"
- 受伤的叹息之壁会启动安全防御机制
- 想把无垢之魂弹回表世界（因为里世界变得危险）
- 但"伤口"会阻止无垢之魂通过
```

**白露弹回的完整逻辑**：
```
叹息之壁受腐蚀
    ↓
叹息之壁感知到"无垢之魂在危险区域"
    ↓
叹息之壁启动安全防御机制：想把无垢之魂弹回表世界
    ↓
但腐蚀通道无法让无垢之魂通过（门被"伤口"堵住了）
    ↓
叹息之壁只能等待：要么腐蚀消失，要么...
    ↓
如果等待时间超过白露灵魂耐受上限
    ↓
叹息之壁强制执行：把白露灵魂"挤"回表世界（不管通道是否畅通）
    ↓
白露被弹回表世界（可能伴随"撕裂感"或"强制传送感"）
```

**威压加速弹回的逻辑**：
- 威压驱散恶魔 → 腐蚀消失
- 叹息之壁"伤口"愈合 → 通道畅通
- 白露可以正常通过通道返回（不需要强制"挤"）
- 返回过程更平稳，白露感知更弱

### 战斗失败的返回逻辑（威压加速关闭）

详见 [#机制:契约体系] 的"威压与缝隙关闭"模块。

**核心流程**：
1. 林奕被怪物杀死 → 威压释放 → 恶魔被驱散
2. 恶魔消失 → 腐蚀消失 → 叹息之壁开始修复
3. 白露通过叹息之壁弹回表世界
4. 林奕通过魂引返回表世界
5. 如果还有残余恶魔 → 林奕复活后继续战斗

**契约的保底机制**：
```
如果林奕在缝隙完全关闭前未能返回
    ↓
魂引发挥作用
    ↓
契约强制执行：把林奕的灵魂"拉"回白露身边
    ↓
林奕在表世界"复活"（肉体重塑在白露附近）
```

- 魂引 = 连接林奕与白露的无形纽带
- 即使缝隙关闭，魂引依然有效
- 契约的力量可以"绕开"叹息之壁，直接把林奕拉回表世界
- 但这种方式会让林奕的"复活"位置不可控（可能突然出现在白露身边）

**林奕的选择**：
- 如果放弃战斗离开里世界 → 白露下次出现，怪物还在 → 白露灵魂会被撕碎
- 如果继续战斗 → 林奕独自面对剩余怪物 → 但至少能清理干净

**为什么不能靠"让白露弹回来"躲避战斗？**
- 白露弹回是暂时的，她的灵魂会耐受限届满后自动弹回
- 但下一次白露出现在某地，缝隙会重新形成
- 如果之前没杀干净，怪物会直接出现在新缝隙中
- 所以林奕必须**清场**，不能留尾巴

### 情况2的伏笔设计

```
【中期·白露提前返回几秒】
白露："你刚才去哪了？我好像没看到你……"
林奕："没有啊，我一直在这里。"
白露："……可能是我眼花了。"

【后期·白露提前返回几十秒】
白露明显感受到林奕"消失"
开始追问，成为察觉真相的关键节点
```

### 返回后

- 两人同时返回时：白露以为只是做了个梦，林奕假装"你刚才走神了一下，没事吧"
- 白露提前返回时：林奕返回后需要解释"刚才去了一下厕所/接了个电话"

## 十年空白期的解释

### 核心设定

`[#剧情事件:十年前闪回序章]`中，契约能力就被赐予了，但处于"沉睡状态"。

### 缝隙形成的完整条件

缝隙形成需要**两个条件同时满足**：

| 条件 | 作用 | 白露以前 | 林奕觉醒后 |
|------|------|----------|------------|
| **叹息之壁开门** | 无垢之魂散发气息 → 叹息之壁为同源之物开门 | ✅ 有（天生） | ✅ 有 |
| **恶魔聚集腐蚀** | 恶魔被吸引到缝隙区域 → 恶意腐蚀叹息之壁 | ❌ 没有 | ✅ 有 |

### 为什么白露以前没有遭遇怪物？

**根本原因**：十年间恶魔无法被有效吸引到白露身边。

```
【形成条件分析】
白露出现在某地 → 叹息之壁感知到"同源气息" → 叹息之壁开门（缝隙雏形）
                                          ↓
但恶魔被吸引需要"特定的信号"
这个信号 = 林奕契约力量苏醒后散发的气息

【十年间】
- 白露的无垢之魂存在，但气息非常微弱（童年期）
- 叹息之壁虽然会"开门"，但门很小，不足以让恶魔察觉
- 恶魔没有"理由"聚集到这个区域
- 缝隙即使短暂形成，也会在恶魔腐蚀之前就被叹息之壁修复

【青春期觉醒后】
- 林奕的契约力量开始苏醒
- 林奕的气息中带有飨食之主的力量印记
- 这股气息成为了"恶魔探测器"的信号
- 恶魔被林奕的气息吸引 → 同时也发现了白露的缝隙
- 缝隙被恶魔腐蚀扩大 → 稳定的缝隙形成
- 怪物开始在缝隙中出现
```

**简述**：白露的"无垢之魂"负责让叹息之壁开门，但"恶魔聚集"这个动作需要林奕的气息作为信号。十年间林奕沉睡，没有信号，所以恶魔不会聚集，白露不会遭遇怪物。

**矛盾澄清**：
- "叹息之壁为白露开门"和"林奕的气息吸引恶魔"是**两个不同的机制**，不矛盾
- 叹息之壁开门是自动反应（白露的无垢之魂）
- 恶魔聚集是被动吸引（林奕的气息信号）
- 两者共同作用，才形成完整的缝隙危机

**与"威压驱散"的关系**：
- 详见 [#机制:契约体系] 的"气息信号"模块
- 林奕平时散发气息（吸引恶魔），死亡时释放威压（驱散恶魔）
- 这是两种不同的力量表现形式，互不冲突
