# 底层机制: `[#机制:双轨世界]`
- **绝对限制**: 表世界与里世界重叠存在，缝隙是唯一的通道入口；里世界时间流速远快于表世界；白露灵魂耐受上限为15-20分钟
- **绕过条件**: 无

## 表世界

- 青春校园、阳光日常的现代都市
- 白露和王皓在此生活
- 人类正常生活的空间

## 里世界（恶魔猎场）

- 隐藏在阴影中的修罗场
- 表面与表世界重叠，但只在"缝隙"出现时才能进入
- 充满反生命、反物质的逆化力场

## 缝隙形成机制（核心触发）

### 形成条件

```
白露出现在某地 → 恶魔被"无垢之光"吸引聚集 → 恶意积累腐蚀叹息之壁 → 缝隙形成
```

### 关键区分

| 角色 | 进入方式 | 原因 |
|------|----------|------|
| 林奕 | **完整身体**进入 | 有契约 + 死亡过 + 被注入无垢之光 = 能承受里世界完整压力 |
| 白露 | **只有无垢之魂**进入 | 只有无垢之光，身体留在表世界（原地发呆状态） |

### 保护机制

```
缝隙形成 → 白露无垢之魂进入里世界（像一团光芒漂浮）
                        ↓
        林奕在里世界守护这团光芒
                        ↓
        击杀恶魔 OR 等待缝隙消失
                        ↓
        白露无垢之魂回到身体 → 醒来（以为自己只是走神了一下/做了个短梦）
        林奕从里世界返回 → 假装"刚好在旁边"/"你没事吧？"
```

## 时间差机制

### 核心规则

```
里世界时间和表世界时间流速不同
缝隙越稳定，时间差越小
```

### 时间差比例

| 阶段 | 战斗时长 | 表世界时间 | 比例 | 说明 |
|------|----------|-----------|------|------|
| **前期**（灰烬级） | 30分钟 | **1秒** | 1:1800 | 缝隙极不稳定，时间差极大 |
| **中期**（黑曜级） | 1-2小时 | 30秒-1分钟 | 1:120~1:120 | 缝隙逐渐稳定 |
| **后期**（灾厄级） | 3-5小时 | 3-5分钟 | 1:60 | 缝隙更稳定 |
| **极端**（最终战） | 10+小时 | 10-15分钟 | 1:40 | 缝隙非常稳定 |

### 白露的灵魂耐受上限

- 无论时间差多少，白露灵魂在里世界最多停留 **15-20分钟（主观感受）**
- 超过耐受上限 → 灵魂被自动弹回身体 → 白露"醒来"

### 白露的表现

| 阶段 | 表世界时间 | 旁人视角 | 白露感受 |
|------|-----------|----------|----------|
| 前期 | 1秒 | 完全察觉不到，只觉得白露"眨眼了一下" | 做了一个很短的梦 |
| 中期 | 30秒-1分钟 | 可能觉得她"走神了一会儿" | 做了个稍长的梦 |
| 后期 | 3-5分钟 | 可能会关心"你刚才怎么了" | 做了个比较清晰的噩梦 |
| 极端 | 10-15分钟 | 明显异常，需要找借口 | 记住了更多细节 |

## 白露的状态

### 里世界中的白露

- **无垢之魂形态**：一团漂浮在里世界的光芒
- **意识状态**：半梦状态
  - 能看到模糊的画面（林奕战斗的影子）
  - 能感受到情绪（林奕的绝望/坚持）
  - 但不能移动、不能说话、不能互动
- **身体状态**：留在原地，眼神放空，像在"发呆"

### 醒来后的白露

- 以为自己只是"走神"了一下或"做了个梦"
- 梦境内容模糊：感觉有光、有模糊的声音、有危险的感觉
- 以为是正常现象，不会深究
- **后期**：开始做"连续的噩梦"，梦境内容更清晰

## 林奕的行为

### 进入方式

- 白露出现 → 缝隙形成 → 林奕**同时**被拉入里世界
- 不需要主动进入缝隙

### 战斗原则

1. **优先击杀**：尽可能在白露灵魂耐受期内杀光怪物
2. **守护光芒**：白露的灵魂是核心目标，不能让它被怪物碰到
3. **引导撤离**：如果来不及击杀，带着白露的灵魂撤离危险区域

### 返回机制

| 情况 | 触发条件 | 表世界表现 |
|------|----------|-----------|
| **情况2（前期为主）** | 林奕在白露耐受期内击杀所有怪物，缝隙消失 | 两人同时返回，白露以为只是发呆 |
| **情况1（中后期出现）** | 白露灵魂耐受到期，被弹回表世界；林奕继续战斗直到缝隙消失 | 白露先醒，感受到"林奕消失了一会儿" |

### 情况1的伏笔设计

```
【中期·白露提前返回几秒】
白露："你刚才去哪了？我好像没看到你……"
林奕："没有啊，我一直在这里。"
白露："……可能是我眼花了。"

【后期·白露提前返回几十秒】
白露明显感受到林奕"消失"
开始追问，成为察觉真相的关键节点
```

### 返回后

- 两人同时返回时：白露以为只是做了个梦，林奕假装"你刚才走神了一下，没事吧"
- 白露提前返回时：林奕返回后需要解释"刚才去了一下厕所/接了个电话"

## 十年空白期的解释

### 核心设定

`[#剧情事件:十年前闪回序章]`中，契约能力就被赐予了，但处于"沉睡状态"。

### 时间线

1. **十年前火灾时**（见`[#剧情事件:十年前闪回序章]`）：飨食之主闻到了"无垢之光"的味道，赐予沉睡的契约能力（单向安排，男主不知情）
2. **十年间沉睡的原因**：灵魂沉睡、无足够缝隙、叹息之壁完好
3. **觉醒触发**：男主进入青春期（16-17岁），契约力量开始苏醒

### 觉醒后果

- 苏醒的气息被里世界感知
- 缝隙开始更容易被腐蚀
- 恶魔开始被吸引到白露身边
