# 底层机制: `[#机制:双轨世界]`

- **绝对限制**: 表世界与里世界重叠存在，缝隙是唯一的通道入口；里世界时间流速远快于表世界；白露灵魂耐受上限为15-20分钟
- **绕过条件**: 无

## 表世界

- 青春校园、阳光日常的现代都市
- 白露和王皓在此生活
- 人类正常生活的空间

## 里世界（恶魔猎场）

- 隐藏在阴影中的修罗场
- 表面与表世界重叠，但只在"缝隙"出现时才能进入
- 充满反生命、反物质的逆化力场

## 缝隙形成机制（核心触发）

### 形成条件

```
白露出现在某地 → 无垢之魂的气息散发
                                    ↓
                    林奕的气息散发（契约力量）
                                    ↓
                    叹息之壁感知到"无垢之魂"
                                    ↓
                    同时感知到无垢之魂有"魂引"连接到飨食之主的气息
                                    ↓
                    【关键】叹息之壁误判为"一体" → 启动陷阱机制（详见 [#机制:叹息之壁] 的"叹息之壁的陷阱机制"）
                                    ↓
                    叹息之壁打开大门
                                    ↓
                    无垢之魂与林奕被一同"吸入"里世界
                                    ↓
                    林奕的气息吸引恶魔聚集（详见 [#机制:契约体系] 的"气息信号"）
                                    ↓
                    恶魔的恶意腐蚀叹息之壁的"门"区域 → 缝隙扩大
```

### 恶魔腐蚀的原理

| 要素 | 说明 |
|------|------|
| **腐蚀来源** | 恶魔的恶意 = 里世界对表世界"入侵者"的敌意 |
| **腐蚀本质** | 恶魔靠近叹息之壁时，会释放暗黑能量腐蚀屏障 |
| **腐蚀效果** | "门"被腐蚀后变大 = 缝隙扩大 = 里世界压力增强 |
| **腐蚀结果** | 白露灵魂和林奕被迫卷入更深的里世界 |

### 林奕与白露的进入方式区分

| 角色 | 进入方式 | 进入原因 |
|------|----------|----------|
| **白露** | 叹息之壁陷阱机制 | 叹息之壁误判一体，吸入里世界 |
| **林奕** | 被叹息之壁"吸入"（因魂引连接） | 魂引让叹息之壁误判为"一体" |

**林奕被吸入的原理**：
- 魂引让林奕与白露"绑定"在一起
- 叹息之壁误判为"一体"
- 叹息之壁打开大门时，把林奕也一起带进去了

详见 [#机制:叹息之壁] 的"飨食之主与叹息之壁"章节。

## 时间差机制

### 核心规则

```
里世界时间和表世界时间流速不同
缝隙越稳定，时间差越小
```

### 时间差比例

| 阶段 | 战斗时长 | 表世界时间 | 比例 | 说明 |
|------|----------|-----------|------|------|
| **前期**（灰烬级） | 30分钟 | **1秒** | 1:1800 | 缝隙极不稳定，时间差极大 |
| **中期**（黑曜级） | 1-2小时 | 30秒-1分钟 | 1:120~1:120 | 缝隙逐渐稳定 |
| **后期**（灾厄级） | 3-5小时 | 3-5分钟 | 1:60 | 缝隙更稳定 |
| **极端**（最终战） | 10+小时 | 10-15分钟 | 1:40 | 缝隙非常稳定 |

### 白露的灵魂耐受上限

- 无论时间差多少，白露灵魂在里世界最多停留 **15-20分钟（主观感受）**
- 超过耐受上限 → 灵魂被自动弹回身体 → 白露"醒来"

## 白露的状态

### 里世界中的白露

- **无垢之魂形态**：一团漂浮在里世界的光芒
- **意识状态**：半梦状态
  - 能看到模糊的画面（林奕战斗的影子）
  - 能感受到情绪（林奕的绝望/坚持）
  - 但不能移动、不能说话、不能互动
- **身体状态**：留在原地，眼神放空，像在"发呆"

### 醒来后的白露

- 以为自己只是"走神"了一下或"做了个梦"
- 梦境内容模糊：感觉有光、有模糊的声音、有危险的感觉
- 以为是正常现象，不会深究
- **后期**：开始做"连续的噩梦"，梦境内容更清晰

## 林奕的行为

### 进入方式

- 白露出现 → 缝隙形成 → 林奕**同时**被拉入里世界
- 不需要主动进入缝隙
- 林奕依靠契约力量在里世界行动，与白露的弹回无直接关联

### 战斗原则

1. **优先击杀**：尽可能在白露灵魂耐受期内杀光怪物
2. **守护光芒**：白露的灵魂是核心目标，不能让它被怪物碰到

### 返回机制

**林奕的返回**：通过**魂引**返回表世界，不是通过缝隙。
**白露的返回**：被叹息之壁弹回表世界（缝隙修复完成后）。

**两种大情况**：

**情况A：无怪物或怪物被清除**
```
没有怪物聚集 → 没有腐蚀
    ↓
叹息之壁开始修复
    ↓
叹息之壁修复完成 → 缝隙关闭
    ↓
叹息之壁将无垢之魂弹回表世界
    ↓
林奕通过魂引返回表世界
```

**情况B：有怪物**
```
怪物被吸引聚集 → 腐蚀持续存在
    ↓
【情况B-1：能清除怪物】
    林奕击杀或驱散怪物
        ↓
    腐蚀消失 → 叹息之壁开始修复
        ↓
    叹息之壁修复完成 → 缝隙关闭
        ↓
    叹息之壁将无垢之魂弹回表世界
        ↓
    林奕通过魂引返回表世界

【情况B-2：无法清除怪物】
    无垢之魂达到耐受界限
        ↓
    叹息之壁强制将无垢之魂弹回表世界（可能有损伤）
        ↓
    腐蚀继续存在 → 缝隙继续存在
        ↓
    林奕需要继续战斗
        ↓
    直到所有怪物被杀（或被驱散）
        ↓
    腐蚀清除 → 缝隙修复关闭
        ↓
    林奕通过魂引返回表世界
```

**威压的作用**：
- 驱散低级怪物
- 高级怪物不会被威压驱散，必须击杀

#### 白露弹回机制

**叹息之壁的双重状态**：
```
叹息之壁（正常状态）：
- 允许无垢之魂在表世界与里世界之间通行
- 缝隙 = 为无垢之魂开启的门

叹息之壁（受腐蚀状态）：
- 腐蚀 = 叹息之壁的"伤口"
- 受伤的叹息之壁会启动安全防御机制
- 想把无垢之魂弹回表世界（因为里世界变得危险）
- 但"伤口"会阻止无垢之魂通过
```

**白露弹回的完整逻辑**：
```
叹息之壁受腐蚀
    ↓
叹息之壁感知到"无垢之魂在危险区域"
    ↓
叹息之壁启动安全防御机制：想把无垢之魂弹回表世界
    ↓
但腐蚀通道无法让无垢之魂通过（门被"伤口"堵住了）
    ↓
叹息之壁只能等待：要么腐蚀消失，要么...
    ↓
如果等待时间超过白露灵魂耐受上限
    ↓
叹息之壁强制执行：把白露灵魂"挤"回表世界（不管通道是否畅通）
    ↓
白露被弹回表世界（可能伴随"撕裂感"或"强制传送感"）
```

### 十年空白期的解释

#### 核心设定

`[#剧情事件:十年前闪回序章]`中，契约能力就被赐予了，但处于"沉睡状态"。

#### 为什么白露以前没有遭遇怪物？

**根本原因**：林奕契约沉睡，没有飨食之主印记或气息，所以不会被叹息之壁判断为"异常"。

```
【缝隙形成机制】
叹息之壁感知到"无垢之魂"
    ↓
同时感知到无垢之魂有"魂引"连接到飨食之主的气息
    ↓
叹息之壁误判为"一体" → 启动陷阱机制 → 打开大门

【十年间】
- 林奕契约沉睡 → 没有飨食之主的气息
- 叹息之壁只感知到"无垢之魂"
- 不会误判为"一体" → 不会启动陷阱机制
- 叹息之壁不会开门
- 白露不会进入里世界 → 不会遭遇怪物

【青春期觉醒后】
- 林奕契约苏醒 → 带有飨食之主的气息
- 叹息之壁感知到"无垢之魂+飨食之主印记"
- 误判为"一体" → 启动陷阱机制
- 叹息之壁打开大门 → 缝隙形成
- 白露进入里世界 → 遭遇怪物
```
