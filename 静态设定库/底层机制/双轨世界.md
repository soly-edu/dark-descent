# 底层机制: `[#机制:双轨世界]`

- **绝对限制**: 表世界与里世界重叠存在，缝隙是唯一的通道入口；里世界时间流速远快于表世界；白露灵魂耐受上限为15-20分钟
- **绕过条件**: 无

## 表世界

- 青春校园、阳光日常的现代都市
- 白露和王皓在此生活
- 人类正常生活的空间

## 里世界（恶魔猎场）

- 隐藏在阴影中的修罗场
- 表面与表世界重叠，但只在"缝隙"出现时才能进入
- 充满反生命、反物质的逆化力场

## 缝隙形成机制（核心触发）

### 形成条件

```
白露出现在某地 → 无垢之魂的气息散发 → 叹息之壁感知到"同源气息"
                                    ↓
                    叹息之壁对无垢之魂的反应："开门"
                                    ↓
                    恶魔被"无垢之光"吸引聚集 → 恶意积累
                                    ↓
                    恶意腐蚀叹息之壁的"门"区域 → 缝隙扩大
```

### 缝隙的本质

缝隙不是"撕裂"出来的，而是叹息之壁对无垢之魂的"反应"。

- 无垢之魂与叹息之壁**同源**
- 叹息之壁会为同源之物"开门"
- 这道门就是缝隙

### 关键区分

| 角色 | 进入方式 | 原因 |
|------|----------|------|
| 林奕 | **完整身体**进入 | 有契约 + 死亡过 + 被注入无垢之光 = 能承受里世界完整压力 |
| 白露 | **只有无垢之魂**进入 | 只有无垢之光，身体留在表世界（原地发呆状态） |

### 为什么飨食之主不能制造缝隙或通过缝隙？

| 方式 | 原因 | 结果 |
|------|------|------|
| 飨食之主主动制造缝隙 | 缝隙是叹息之壁对无垢之魂的"反应"，不是飨食之主能控制的 | ❌ 不可能 |
| 飨食之主通过缝隙进入表世界 | 飨食之主是里世界最深处的存在，被束缚在那边 | ❌ 不可能 |
| 飨食之主直接触碰表世界 | 存在形式不允许，无法跨越表里世界的界限 | ❌ 不可能 |

**飨食之主的限制**：
- 他是里世界的"原住民"，被锁在自己的领域
- 他无法主动制造缝隙（那是叹息之壁对无垢之魂的反应）
- 他只能等待缝隙自然形成，然后**等待**

### 缝隙与飨食之主的关系

```
飨食之主的困境：
- 无法主动制造缝隙
- 无法穿过叹息之壁
- 无法直接触碰表世界

飨食之主的解决方案：
- 找一个能在表里世界之间活动的"工具"
- 这个工具就是林奕
- 林奕能进入缝隙、杀死恶魔，保护白露
- 而林奕的"保护"行为，恰恰在帮飨食之主雕刻钥匙
```

### 保护机制

```
缝隙形成 → 白露无垢之魂进入里世界（像一团光芒漂浮）
                        ↓
        林奕在里世界守护这团光芒
                        ↓
        击杀恶魔 OR 等待缝隙消失
                        ↓
        白露无垢之魂回到身体 → 醒来（以为自己只是走神了一下/做了个短梦）
        林奕从里世界返回 → 假装"刚好在旁边"/"你没事吧？"
```

## 十年空白期的解释

### 核心设定

`[#剧情事件:十年前闪回序章]`中，契约能力就被赐予了，但处于"沉睡状态"。

### 为什么白露以前没有遭遇怪物？

**关键原因**：林奕的契约力量处于沉睡状态

```
十年前火灾：
- 白露的无垢之光觉醒了（那次火灾本身就是缝隙的雏形）
- 飨食之主闻到了"无垢之光"的味道
- 赐予林奕沉睡的契约能力（单向安排，男主不知情）
    ↓
十年间：
- 林奕的契约力量持续沉睡
- 灵魂沉睡 = 气息微弱
- 叹息之壁感知不到明显的"同源气息"
- 缝隙几乎不会形成
- 恶魔不会聚集到白露身边
    ↓
青春期觉醒（约16-17岁）：
- 契约力量开始苏醒
- 林奕散发的气息变强
- 气息中带有飨食之主的力量（契约的源头）
- 这股气息被叹息之壁感知
- 缝隙开始更容易被腐蚀
- 恶魔开始被吸引到白露身边
```

**简述**：不是白露以前安全，而是林奕沉睡时，他的气息掩盖了白露的无垢之光。当林奕觉醒后，反而"激活"了这个系统。
