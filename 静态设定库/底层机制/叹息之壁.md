# 底层机制: `[#机制:叹息之壁]`

- **绝对限制**: 由秩序法则编织而成的屏障，与无垢之魂同源；里世界原生怪物触碰即被净化
- **绕过条件**: 悖论之钥（表层同源+内里极暗）

## 本质

叹息之壁是**秩序法则的具现化**。

```
叹息之壁 = 秩序法则编织的屏障
无垢之魂 = 秩序法则在白露身上的具现
    ↓
同源共鸣 = 无垢之魂天然被叹息之壁视为"同类"
```

**叹息之壁的判定逻辑**：
- 它不会主动攻击"同源之物"
- 它会放行与秩序相关的存在
- 它只对"里世界的入侵者"进行净化

## 叹息之壁的陷阱机制

详见 [#机制:双轨世界] 的"叹息之壁的真实目的"。

**简化说明**：

```
叹息之壁感知到"无垢之魂+魂引连接飨食之主印记"
    ↓
叹息之壁误判为"一体"
    ↓
打开大门，计划：吸入→分离→困住林奕→弹回白露
```

**注意**：叹息之壁的"开门"不是"邀请"，而是一个**陷阱机制**。

## 无垢之魂的保护机制

叹息之壁不只是屏障，更是一个**监控与召回系统**。

### 怪物触碰无垢之魂的后果

当里世界怪物触碰到白露的无垢之魂：

```
怪物触碰无垢之魂
    ↓
无垢之魂外部被污染
    ↓
叹息之壁检测到"纯净之物被篡改"
    ↓
触发紧急召回机制
    ↓
强制将无垢之魂弹回表世界
    ↓
外部污染被自动净化
    ↓
白露恢复正常
```

### 为什么飨食之主不能直接利用怪物污染白露？

| 污染方式 | 结果 |
|----------|------|
| 怪物直接触碰 | 叹息之壁检测到 → 弹回 → 自动净化 → **无效** |
| 心蚀（通过魂引渗透） | 从内部渗透 → 叹息之壁识别为"同源代谢" → **有效** |

**核心区别**：
- 外部污染 = 入侵 → 被净化
- 心蚀 = 内部变质 → 不被识别为入侵

这就是飨食之主需要林奕的原因——只有通过魂引的**渐进式心蚀**，才能让白露的灵魂在保持"同源产物"属性的同时完成极性反转。

## 悖论之钥的突破原理

> *只有披着圣洁外衣的极恶，才能骗过神明的门锁。*

### 突破机制

悖论之钥不是"打破"叹息之壁，而是利用**同源属性**骗过判定。

```
悖论之钥触碰叹息之壁
    ↓
叹息之壁扫描表面（只看外层，不看内里）
    ↓
发现表层仍是"无垢之光"（同源之物）
    ↓
叹息之壁的反应："这是同类的延伸，放行"
    ↓
悖论之钥穿过屏障
    ↓
穿过瞬间，内部极高密度的暗黑能量冲击屏障
    ↓
叹息之壁被冲击 → 变薄弱/不稳定
```

### 屏障的命运

- 不是彻底崩塌（那样表里世界会融合，表世界变成炼狱）
- 而是变薄弱/不稳定
- 飨食之主降临后，屏障会继续削弱，但不会立刻消失

### 为什么飨食之主不能直接穿过叹息之壁？

| 方式 | 原因 | 结果 |
|------|------|------|
| 飨食之主直接穿过叹息之壁 | 里世界最深处存在，无法移动到表世界侧 | ❌ 不可能 |
| 飨食之主制造缝隙进入 | 只能等待缝隙自然形成，无法主动制造 | ❌ 不可能 |
| 飨食之主直接触碰表世界 | 存在形式不允许，无法跨越表里世界的界限 | ❌ 不可能 |

飨食之主是里世界的"原住民"，被锁在自己的领域。他只能通过林奕这个"工具"间接完成计划。
