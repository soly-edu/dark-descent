# 底层机制: `[#机制:吸收机制]`
- **绝对限制**: 林奕必须先经历N次死亡+肉体改造，才能承受吸收；吸收是被动的，击杀即吸收，无法选择"击杀但不吸收"
- **绕过条件**: 灾厄级吸收有极高概率彻底"受肉"
- **作用范围**: 林奕、镜灵、心蚀四阶段

## 吸收的前提：肉体改造

林奕并非天生可以吸收怪物。他的肉体需要经过**改造**才能承受暗黑能量。

### 改造流程

```
林奕死亡
↓
镜灵缝合灵魂 + 改造肉体（按飨食之主计划）
↓
复活
↓
重复N次
↓
改造完成 → 肉体可以承受吸收
```

### 改造内容

| 改造项目 | 效果 | 副作用 |
|---------|------|--------|
| 血管强化 | 可以承受暗黑能量流动 | 血管隐约可见黑色纹路 |
| 神经改造 | 可以承受怪物意志侵蚀 | 周期性偏头痛、幻听 |
| 灵魂扩容 | 可以暂存更多暗黑能量 | 记忆片段丢失 |
| 皮肤角质化 | 肉体防御提升 | 皮肤下长出黑色硬化角质 |

### 林奕的感知

- 每次复活后，感觉身体"有些不同"
- 不知道是改造，只以为是"死亡的代价"或"复活的后遗症"
- 表现为：体温下降、味觉变淡、某些记忆模糊

---

## 吸收的触发：契约武器

改造完成后，镜灵按飨食之主的计划赠予林奕**契约武器**。

### 契约武器的本质

- 由飨食之主用**同源契约之力**附魔的武器
- 武器与林奕的契约绑定，是他身体的一部分
- 代表作：【怨骨·初刃】

### 吸收机制

```
林奕用契约武器击杀怪物
↓
怪物死亡瞬间
↓
暗黑能量/怪物素材释放
↓
契约武器自主选择适合素材 → 融入武器 → 武器增强
↓
剩余能量注入林奕肉体 → 林奕增强
↓
超限部分通过魂引倒灌给白露 → 心蚀
```

**核心规则**：
- **击杀 = 吸收**，一体两面
- 林奕**无法选择**"击杀但不吸收"
- 这是死局的核心——想保护白露就必须杀怪，杀了就必然伤害她

---

## 契约武器的自主成长

契约武器有自己的"意志"，会从怪物素材中**自主选择**适合的部件融入自身。

### 成长流程

```
契约武器击杀怪物
↓
怪物素材释放（骨骼、血肉、核心、意志碎片等）
↓
契约武器"审视"素材
↓
选择适合的素材 → 融入武器 → 武器形态/属性变化
↓
剩余素材 → 进入林奕肉体
```

### 关键特性

| 特性 | 说明 |
|------|------|
| **自主选择** | 武器有自己的判断标准，林奕无法干预 |
| **林奕被动** | 林奕不知道武器在"挑选"，只看到武器变化 |
| **双重增强** | 武器增强 + 林奕增强，同时发生 |
| **优先级** | 武器先选，剩下的给林奕 |

### 林奕的认知

- 他知道"这把武器会随我一起变强"
- 他不知道武器有自主意志
- 他不知道武器选择后"剩下的"才给他
- 他不知道超限部分倒灌给白露

## 吸收等级效果

| 怪物等级 | 吸收效果 | 副作用 | 心蚀影响 |
|----------|----------|--------|---------|
| 灰烬级 | 轻微肉体强化 | 皮肤角质化、狂躁感 | 轻度溢出（5%） |
| 黑曜级 | 精神海冲击，获得强大特性 | 怪物记忆插入、周期性失控 | 中度溢出（20-30%） |
| 灾厄级 | 极度强化，接近里世界法则 | 极高概率"受肉" | 溢出率飙升（50-80%） |

---

## 吸收上限与受肉

### 吸收上限

- 当吸收量逼近临界点时，五官会渗出黑泥
- 这是"容器即将溢出"的警告信号

### 受肉

> *当怪物意志反客为主，骑士就不再是骑士了。*

- **受肉**：怪物意志彻底吞噬林奕的人格，他变成真正的怪物
- 灾厄级吸收有**极高概率**触发受肉
- 受肉后，林奕不再是人类，成为"王级恶鬼"
