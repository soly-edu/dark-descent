# 底层机制: `[#机制:心蚀传导机制]`

- **绝对限制**: 林奕在里世界战斗 → 暗黑能量溢出 → 通过魂引传导 → 白露灵魂腐蚀
- **绕过条件**: 无（真正的死局，不存在合法 bypass）

## 传导链条

```
林奕在里世界战斗，吸收怪物的暗黑能量
                ↓
        林奕变强，但身体承受不了的部分
                ↓
        以灵魂传导的方式通过魂引倒灌给无垢之魂
                ↓
        白露的灵魂遭受心蚀伤害
                ↓
        心蚀积累导致无垢之魂逐渐极性反转
                ↓
                详见 [#机制:心蚀四阶段]
```

## 魂引的持续传导机制

**核心规则**：魂引是始终存在的无形通道，连接林奕的灵魂与白露的灵魂（无垢之魂）。

```
魂引 = 一根无形的管子
连接林奕的灵魂与白露的灵魂（无垢之魂）
两端永远相连，无论林奕在里世界还是表世界
    ↓
只要林奕体内存在暗黑能量
就会持续通过魂引向白露渗透
    ↓
渗透是持续进行的，不存在"完成"一说
每次心跳 = 一次能量传递
```

详见 [#机制:双轨世界] 的"缝隙形成机制"了解魂引在缝隙形成中的作用。

## 白露灵魂弹回后的心蚀传导

**核心规则**：弹回表世界不中断魂引的传导，因为魂引跨越表里两个世界。

```
白露被弹回表世界
    ↓
魂引依然连接（跨越表里世界）
    ↓
林奕体内的暗黑能量继续通过魂引传递
    ↓
白露灵魂虽回到身体，但暗黑能量已留在她灵魂内部
```

详见 [#机制:双轨世界] 了解缝隙形成机制。

## 三层伤害机制

| 伤害层面 | 具体表现 |
|----------|----------|
| **共情阻断** | 剥夺"爱"的能力，无法体会快乐和感动 |
| **认知倒错** | 美好记忆被毒化，温暖变成阴冷 |
| **幻痛共鸣** | 真实体验林奕在里世界的肉体痛苦 |

## 溢出机制

| 林奕状态 | 溢出率 |
|----------|--------|
| 安全容量内 | 5% |
| 超频爆发（濒死状态） | 80% |

**核心悲剧**：他打得越惨烈，溢出的暗黑能量越恐怖

## 弹回时机的叙事价值

| 弹回时机 | 白露看到的内容 | 叙事作用 |
|----------|----------------|----------|
| 前期（战斗刚开始） | 什么都没看到就醒了 | 模糊噩梦的种子 |
| 中期（战斗中途） | 看到林奕厮杀的模糊画面 | 开始怀疑"这是不是真的" |
| 中后期（关键死亡） | 看到林奕被斩杀并重塑 | "他不是普通人"的认知突破 |
| 后期（战斗尾声） | 看到完整的战斗和代价 | 触发第三阶段·倒影 |

**弹回时机设计原则**：
- 不是"战斗多久就弹回"，而是"特定时刻弹回"
- 弹回时机应该服务于剧情节奏，选择最能产生冲击的画面
- 弹回后白露记得的内容清晰度 = 弹回越晚，记得越清楚

详见 [#机制:双轨世界] 了解时间差与弹回的具体机制。

## 战斗结束条件

详见 [#机制:双轨世界]。

**简述**：
| 结束方式 | 触发条件 | 结果 |
|----------|----------|------|
| **方式一：清场** | 林奕击杀所有怪物 | 缝隙消失，两人返回 |
| **方式二：强制关闭** | 缝隙维持时间达到上限 | 两人被弹回 |
| **方式三：白露触发** | 白露灵魂耐受上限到期 | 白露先弹回，林奕继续战斗 |

## 极致两难困境

- **如果林奕完全停止战斗**：白露的灵魂会被恶魔撕碎（灵魂死亡）
- **如果林奕战斗**：暗黑能量会通过魂引污染白露的灵魂
- **逻辑闭环**：

```
林奕为了保护白露的灵魂 → 必须去杀怪
为了杀怪 → 必须吸收怪物变强
变强产生的溢出 → 又在把白露推向精神死亡
```

**这是真正的死局，没有出路。**
