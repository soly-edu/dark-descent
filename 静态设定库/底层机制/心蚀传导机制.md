# 底层机制: `[#机制:心蚀传导机制]`
- **绝对限制**: 林奕在里世界战斗 → 暗黑能量溢出 → 通过无垢之光倒灌 → 白露灵魂腐蚀
- **绕过条件**: 无（真正的死局，不存在合法 bypass）

## 传导链条

```
白露出现在某地 → 缝隙形成 → 白露灵魂进入里世界
                                        ↓
                林奕在里世界战斗，吸收怪物的暗黑能量
                                        ↓
                林奕变强，但容器溢出
                                        ↓
                溢出的暗黑能量通过"无垢之光/魂引"倒灌给白露的灵魂
                                        ↓
                白露的灵魂遭受心蚀伤害
                                        ↓
                心蚀积累导致无垢之魂逐渐极性反转
                                        ↓
                极性完全反转 → 成为"悖论之钥"
```

## 三层伤害机制

| 伤害层面 | 具体表现 |
|----------|----------|
| **共情阻断** | 剥夺"爱"的能力，无法体会快乐和感动 |
| **认知倒错** | 美好记忆被毒化，温暖变成阴冷 |
| **幻痛共鸣** | 真实体验林奕在里世界的肉体痛苦 |

## 溢出机制

| 林奕状态 | 溢出率 |
|----------|--------|
| 安全容量内 | 5% |
| 超频爆发（濒死状态） | 80% |

**核心悲剧**：他打得越惨烈，溢出的暗黑能量越恐怖

## 时间差与心蚀的关系

```
战斗时间（里世界）= 30分钟（前期）~ 10小时（最终战）
表世界时间        = 1秒（前期）~ 15分钟（最终战）

虽然表世界时间短，但白露的灵魂在里世界
所以白露能感受到战斗的全过程
只是时间流速不同
```

### 魂引的持续传导机制

**核心规则**：魂引是始终存在的无形通道，不是只在"战斗时"才工作。

```
魂引 = 一根无形的管子，从林奕心脏延伸至白露灵魂
两端永远相连，无论林奕在里世界还是表世界
    ↓
只要林奕体内存在暗黑能量
就会持续通过魂引向白露渗透
    ↓
渗透是持续进行的，不存在"完成"一说
每次心跳 = 一次能量传递
```

### 白露灵魂弹回后的心蚀传导

**核心规则**：弹回表世界不中断魂引的传导，因为魂引跨越表里两个世界。

```
白露被弹回表世界
    ↓
魂引依然连接（跨越表里世界）
    ↓
林奕体内的暗黑能量继续通过魂引传递
    ↓
白露灵魂虽回到身体，但暗黑能量已留在她灵魂内部
```

### 弹回时机的叙事价值

| 弹回时机 | 白露看到的内容 | 叙事作用 |
|----------|----------------|----------|
| 前期（战斗刚开始） | 什么都没看到就醒了 | 模糊噩梦的种子 |
| 中期（战斗中途） | 看到林奕厮杀的模糊画面 | 开始怀疑"这是不是真的" |
| 中后期（关键死亡） | 看到林奕被斩杀并重塑 | "他不是普通人"的认知突破 |
| 后期（战斗尾声） | 看到完整的战斗和代价 | 触发第三阶段·倒影 |

**弹回时机设计原则**：
- 不是"战斗多久就弹回"，而是"特定时刻弹回"
- 弹回时机应该服务于剧情节奏，选择最能产生冲击的画面
- 弹回后白露记得的内容清晰度 = 弹回越晚，记得越清楚

### 时间差与弹回的关系

| 阶段 | 里世界战斗时间 | 表世界对应时间 | 白露耐受上限 | 弹回可能性 |
|------|---------------|---------------|-------------|-----------|
| 前期（灰烬级） | 30分钟 | 1秒 | 15-20分钟 | 几乎不可能弹回（战斗太快） |
| 中期（黑曜级） | 1-2小时 | 30秒-1分钟 | 15-20分钟 | 可能弹回（战斗拉长） |
| 后期（灾厄级） | 3-5小时 | 3-5分钟 | 15-20分钟 | 一定会弹回 |
| 最终战 | 10+小时 | 10-15分钟 | 15-20分钟 | 多次弹回+强制拉回 |

**最终战弹回设计**：
```
第一次弹回（约15分钟里世界时间）
    ↓ 白露醒来，表世界过了几秒
第二次进入里世界（缝隙仍存在）
    ↓ 继续战斗
第二次弹回
    ↓
...
直到战斗结束
    ↓
白露最终弹回后，不再进入
但可能目睹林奕的最终状态

### 战斗结束条件

**核心原则**：战斗结束 = 所有威胁被清除 或 缝隙自行关闭。

| 结束方式 | 触发条件 | 结果 |
|----------|----------|------|
| **方式一：清场** | 林奕击杀所有怪物，缝隙失去维持能量源 | 缝隙消失，两人同时/先后返回 |
| **方式二：强制关闭** | 缝隙维持时间达到上限（由恶魔数量决定） | 缝隙强制关闭，两人被弹回 |
| **方式三：白露触发** | 白露灵魂耐受上限到期 | 白露先弹回，林奕继续战斗 |

**缝隙关闭后的状态**：
```
缝隙关闭
    ↓
里世界消失
    ↓
林奕：如果还在里世界，会被强制拉回表世界（不一定死亡，可能以重伤状态返回）
    ↓
白露：灵魂回到身体，醒来（可能记得模糊内容）
```
```

## 极致两难困境

- **如果林奕完全停止战斗**：白露的灵魂会被恶魔撕碎（灵魂死亡）
- **如果林奕战斗**：暗黑能量会通过无垢之光污染白露的灵魂
- **逻辑闭环**：

```
林奕为了保护白露的灵魂 → 必须去杀怪
为了杀怪 → 必须吸收怪物变强
变强产生的溢出 → 又在把白露推向精神死亡
```

**这是真正的死局，没有出路。**

## 战斗结束与悖论之钥的形成

### 战斗结束的时机

正常情况下，战斗结束意味着：
- 林奕杀死所有威胁
- 白露安全返回

**但悖论之钥的形成不在"正常战斗结束"的范畴内**——它是一个特殊的终局事件，发生在：
1. 林奕已经消耗殆尽
2. 白露心蚀接近100%
3. 某个致命时刻触发（林奕被击溃、契约断裂）

这意味着悖论之钥的形成不是"战斗胜利"，而是"战斗的终极悲剧结局"。

飨食之主不能直接污染无垢之魂的原因：

1. 叹息之壁是秩序法则的具现化，与无垢之魂**同源**
2. 如果飨食之主直接把暗黑能量灌入 → 会被叹息之壁净化
3. 林奕的战斗让暗黑能量"从内部"渗透无垢之魂
4. 这种污染不会被叹息之壁识别为"入侵"，因为它是通过同源之物吸收的

### 极性反转

| 普通污染 | 悖论之钥（目标） |
|----------|------------------|
| 从外部覆盖 | 从内部渗透 |
| 屏障识别为"入侵" → 净化 | 屏障识别为"同源代谢" → 放行 |
| 失败 | 成功通过屏障 |

### 缝隙与飨食之主的关系

详见 [#机制:双轨世界]。简述：
- 缝隙是叹息之壁对无垢之魂的"反应"，不是飨食之主能制造的
- 飨食之主被束缚在里世界最深处，无法主动跨越边界
- 他只能通过林奕这个"工具"间接完成计划

## 林奕的悲剧定位

```
飨食之主不能做的事：
- 不能直接伸手进里世界抓白露
- 不能直接把暗黑能量灌进缝隙
- 不能直接污染无垢之魂

飨食之主能做的事：
- 等待（可能要几百年）
- 利用林奕这个"工具人"

林奕的每一次杀戮，都是在为飨食之主"雕刻"钥匙
没有林奕，这个计划永远不会成功
林奕不是"被利用的傻瓜"，而是"飨食之主最重要的工具人"
```

## 极暗的终态

```
心蚀达到极限 → 无垢之魂极性完全反转
    ↓
白露不再是"被污染的圣杯"
而是"本身就是暗黑能量的圣杯"（表层仍是同源之光）
    ↓
悖论之钥穿过叹息之壁
    ↓
叹息之壁被冲击 → 变薄弱/不稳定（不是彻底崩塌）
    ↓
飨食之主通过接收的契约残余机制，牵引极暗能量
    ↓
变弱的叹息之壁无法阻挡，飨食之主降临
```

**关于叹息之壁的命运**：
- 不是彻底崩塌（那样表里世界会融合，表世界变成炼狱）
- 而是变薄弱/不稳定
- 飨食之主降临后，屏障会继续削弱，但不会立刻消失
