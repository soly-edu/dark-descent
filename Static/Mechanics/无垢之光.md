# 底层机制: `[#Mechanics:无垢之光]`

- **Constraint**: 白露灵魂的本质，里世界秩序的产物，对黑暗有本能净化作用
- **Bypass_Condition**: [#Mechanics:心蚀四阶段]（内部渗透而非外部污染）
- **Applied_To**: [@Characters:白露]

## 核心机制

### 双重存在

```
白露的身体留在表世界（原地发呆）
白露的灵魂进入里世界（无垢之光形态）
```

### 林奕的感知

- 能看到白露的灵魂在里世界中漂浮（一团光芒）
- 能通过 [#Mechanics:契约体系] 的魂引感知白露的状态
- 林奕的职责是守护这团光芒，直到战斗结束

### 保护作用

当里世界怪物触碰到无垢之魂时，触发 [#Mechanics:叹息之壁] 的紧急召回机制。

### 被污染过程

白露的内里被林奕的 [#Mechanics:溢出机制] 逐渐填满、黑化，最终 [#Mechanics:心蚀四阶段] 达到第四阶段·极暗。

### 悖论之钥的形成

```
表层 = 无垢之光（秩序的产物）
内里 = 极暗之源（暗黑能量的容器）
↓
[#Mechanics:叹息之壁] 对她敞开
↓
[#Mechanics:飨食之主] 降临
```
