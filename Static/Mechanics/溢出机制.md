# 底层机制: `[#Mechanics:溢出机制]`

- **Constraint**: 单次吸收超过灵魂承载力10%，或绝境中超频爆发，触发溢出。比例非线性。
- **Bypass_Condition**: 无
- **Applied_To**: [@Characters:林奕]

## 核心机制

### 触发条件

| 触发类型 | 条件 |
|---------|------|
| 单次超载 | 单次吸收超过灵魂承载力10% |
| 超频爆发 | 绝境中战斗到极限 |

### 溢出比例非线性

```
状态    | 占比
--------|------
安全状态 | ~5%
濒死状态 | ~80%
```

### 溢出物

- 纯粹的暗黑能量
- 包含：里世界极度的狂躁、怪物的怨毒、死亡的冰冷

### 悲剧核心

```
林奕打怪越惨烈
↓
濒死状态越多
↓
溢出比例越高
↓
暗黑能量通过魂引渗透到白露越多
↓
[#Mechanics:心蚀四阶段] 加速
↓
白露被慢性毒杀
```

> ⚠️ **死局**：杀怪变强 = 白露被心蚀慢性毒死；不杀 = 白露被怪物物理撕碎
