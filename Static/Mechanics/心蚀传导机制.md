# 底层机制: `[#Mechanics:心蚀传导机制]`
- **Constraint**: 林奕在里世界战斗 → 暗黑能量溢出 → 通过无垢之光倒灌 → 白露灵魂腐蚀
- **Bypass_Condition**: 无（真正的死局，不存在合法 bypass）

## 传导链条

```
白露出现在某地 → 缝隙形成 → 白露灵魂进入里世界
                                        ↓
                林奕在里世界战斗，吸收怪物的暗黑能量
                                        ↓
                林奕变强，但容器溢出
                                        ↓
                溢出的暗黑能量通过"无垢之光/魂引"倒灌给白露的灵魂
                                        ↓
                白露的灵魂遭受心蚀伤害
                                        ↓
                心蚀积累导致无垢之魂逐渐极性反转
                                        ↓
                极性完全反转 → 成为"悖论之钥"
```

## 三层伤害机制

| 伤害层面 | 具体表现 |
|----------|----------|
| **共情阻断** | 剥夺"爱"的能力，无法体会快乐和感动 |
| **认知倒错** | 美好记忆被毒化，温暖变成阴冷 |
| **幻痛共鸣** | 真实体验林奕在里世界的肉体痛苦 |

## 溢出机制

| 林奕状态 | 溢出率 |
|----------|--------|
| 安全容量内 | 5% |
| 超频爆发（濒死状态） | 80% |

**核心悲剧**：他打得越惨烈，溢出的暗黑能量越恐怖

## 时间差与心蚀的关系

```
战斗时间（里世界）= 30分钟（前期）~ 10小时（最终战）
表世界时间        = 1秒（前期）~ 15分钟（最终战）

虽然表世界时间短，但白露的灵魂在里世界
所以白露能感受到战斗的全过程
只是时间流速不同
```

## 极致两难困境

- **如果林奕完全停止战斗**：白露的灵魂会被恶魔撕碎（灵魂死亡）
- **如果林奕战斗**：暗黑能量会通过无垢之光污染白露的灵魂
- **逻辑闭环**：

```
林奕为了保护白露的灵魂 → 必须去杀怪
为了杀怪 → 必须吸收怪物变强
变强产生的溢出 → 又在把白露推向精神死亡
```

**这是真正的死局，没有出路。**

## 悖论之钥的形成

飨食之主不能直接污染无垢之魂的原因：

1. 叹息之壁是秩序法则，会自动净化里世界的暗黑能量
2. 如果飨食之主直接把暗黑能量灌入 → 会被叹息之壁净化
3. 林奕的战斗让暗黑能量"从内部"渗透无垢之魂
4. 这种污染不会被叹息之壁识别为"入侵"，因为它是从白露灵魂内部产生的

### 极性反转

| 普通污染 | 悖论之钥（目标） |
|----------|------------------|
| 从外部覆盖 | 从内部渗透 |
| 屏障识别为"入侵" → 净化 | 屏障识别为"表世界产物" → 放行 |
| 失败 | 成功通过屏障 |

## 林奕的悲剧定位

```
飨食之主不能做的事：
- 不能直接伸手进里世界抓白露
- 不能直接把暗黑能量灌进缝隙
- 不能直接污染无垢之魂

飨食之主能做的事：
- 等待（可能要几百年）
- 利用林奕这个"工具人"

林奕的每一次杀戮，都是在为飨食之主"雕刻"钥匙
没有林奕，这个计划永远不会成功
林奕不是"被利用的傻瓜"，而是"飨食之主最重要的工具人"
```

## 极暗的终态

```
心蚀100% → 无垢之魂极性完全反转
↓
白露不再是"被污染的圣杯"
而是"本身就是暗黑能量的圣杯"
↓
叹息之壁识别为"表世界产物，只是变黑了"
↓
飨食之主伸手穿过叹息之壁，接过"钥匙"
↓
屏障打开，飨食之主降临
```
